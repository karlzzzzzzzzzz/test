主页卡片布局组件（CardLayout）需求文档

页面：首页 /index.html 类型：新增组件 深度：Medium PRD

1. 背景与目标

首页 Bento 网格中已有多种卡片（项目定位大卡、技术栈卡、作品卡、工作流卡、统计条），但它们各自的 JSX 结构和样式类名独立编写，缺少一个可复用的通用卡片布局骨架。当后续需要在首页新增内容卡片时，开发者需要复制粘贴既有结构再手动调整，结构不统一且容易遗漏无障碍属性。

同时，首页的"精选作品"卡已展示过技术标签（bento-work-tag），但标签放在了卡片底部、与标题分离。用户希望将技术标签上提到标题区，使读者在浏览标题时即可一眼识别该卡片涉及的技术栈。

产品决策：抽象一个通用的 CardLayout 组件，固定"标题区 → 内容区 → 底部区"三段结构，并在标题区内置技术标签展示能力，供首页及未来其他页面复用。

可观测结果：开发者在首页新增卡片时，只需传入 title、techTags、children、footer 四类数据即可得到一张结构完整、无障碍属性齐全、视觉风格统一的卡片。

2. 范围

2.1 P0（本次必须完成）

  • 入口条件：首页 Bento 网格中需要展示一张新内容卡片时，使用 <CardLayout> 组件。
  • P0 动作：
    1. 组件渲染三段结构：标题区（含技术标签）、内容区、底部区。
    2. 标题区展示卡片标题文字 + 0~N 个技术标签胶囊。
    3. 内容区接受任意 ReactNode（文本、列表、图片等）。
    4. 底部区接受任意 ReactNode（操作链接、元信息等）。
  • 完成证据：浏览器中渲染出的卡片视觉上分为三个明确区域，标题区可见技术标签胶囊；无标签时不渲染标签容器。
  • 恢复路径：技术标签数据缺失或为空数组时，标题区只显示标题文字，不报错、不留空容器。

2.2 P1（可后续扩展，本次不做）

  • 卡片可点击整卡跳转（当前由底部链接独立承担跳转）。
  • 标题区图标插槽（当前仅文字标题 + 标签）。
  • 标签的筛选/点击跳转搜索功能。

2.3 明确排除

  • 不替换首页已有的既有卡片结构（作品卡、工作流卡等保持原样，仅在新增卡片时使用本组件）。
  • 不引入第三方 UI 库；使用原生 CSS + 项目既有 CSS 变量。
  • 不涉及后端数据获取；所有数据由调用方以 props 传入。

3. 功能需求

组件签名：<CardLayout title="" techTags=[] footer={} span="" >{children}</CardLayout>。以下需求按模块组织。

FR-01　三段结构渲染

维度说明
FR-01组件固定渲染三个 DOM 区域，顺序为标题区 → 内容区 → 底部区，不可调换。
触发组件挂载即渲染；无条件分支。
处理规则三段均为同级 flex 子元素，纵向排列（flex-direction: column）。内容区 flex-grow: 1 撑满剩余高度，标题区和底部区高度由内容决定。
结果与状态变更无持久化状态；纯展示组件，渲染后不产生副作用。
区域边界标题区与内容区之间、内容区与底部区之间各有一条 1px 分隔线（border-top / border-bottom，颜色取 --border 变量），保证视觉分段。

FR-02　标题区与技术标签

维度说明
FR-02标题区渲染卡片标题文字 + 技术标签胶囊群。
布局标题区分上下两行：第一行为标题文字（可选同行末尾图标/箭头）；第二行为技术标签群，横向排列、超出换行。
字段：title类型 string，必填。渲染为 <h3> 标题，字号 18px，字重 700，颜色取 --text-h。
字段：techTags类型 string[]，可选，默认空数组。每个标签渲染为一个胶囊（span），圆角 999px，字号 11px，等宽字体，颜色取 --accent，背景取 accent 10% 混合。
标签状态hover：标签背景变为 --accent 实色，文字变白，轻微上移 1px。
空标签techTags 为空数组或未传时，不渲染标签容器 DOM（而非渲染空 div），标题区仅显示标题文字。
无障碍标题区容器 role="group"，aria-label 取标题文字。标签 aria-hidden="true"（标签为视觉辅助，不可单独聚焦；若需可点击则在 P1 扩展）。

FR-03　内容区

维度说明
FR-03内容区接受任意 ReactNode，作为组件 children 传入。
触发组件挂载即渲染 children。
处理规则内容区 flex-grow: 1，纵向占满标题区与底部区之间的剩余空间。内部默认 font-size: 14px; line-height: 1.65，颜色 --text。
空内容children 为 null/undefined 时内容区仍渲染容器（保持三段结构完整），容器高度为 0 + padding，不报错。
溢出内容超出卡片高度时，由调用方决定是否滚动；组件默认 overflow: hidden，不自动滚动。如需滚动，调用方可通过 className 覆盖。

FR-04　底部区

维度说明
FR-04底部区接受任意 ReactNode，作为 footer prop 传入。
触发footer prop 非空时渲染底部区；为 null/undefined 时不渲染底部区 DOM，卡片仅保留标题区 + 内容区两段。
处理规则底部区默认 display: flex; justify-content: space-between; align-items: center，适合左侧放元信息、右侧放操作链接的布局。
典型内容左侧：日期 / 阅读时长 / 作者等元信息；右侧："阅读全文 →"、"查看演示"等链接。
分隔底部区与内容区之间有一条 border-top: 1px solid --border 分隔线。

FR-05　网格占位（span）

维度说明
FR-05组件支持通过 span prop 指定在 Bento 12 栏网格中的占位宽度。
字段：span类型 '3' | '4' | '6' | '8' | '12'，可选，默认 '4'。映射为既有 CSS 类 bento-span-{n}。
处理规则组件根元素拼接 cl-card bento-span-{span} 类名。调用方传入非法值时降级为 bento-span-4。
响应式复用 Home.css 中既有的 bento-span-* 响应式断点（≤960px 缩半、≤560px 单列），组件不额外定义断点。

FR-06　视觉风格一致性

维度说明
FR-06卡片视觉复用首页既有 Bento 卡设计语言。
背景玻璃拟态：background: color-mix(surface 72%, transparent) + backdrop-filter: blur(12px)（不支持时降级为实色）。
圆角 / 边框圆角 16px，1px 边框，颜色 --border。
悬停整卡 hover：translateY(-4px) + 紫色阴影 0 12px 32px accent 18%。
入场动画复用 bento-fade-up 入场动画，animation-fill-mode: backwards（避免覆盖 hover 样式，遵循项目既有经验）。
焦点环卡片内可交互元素 :focus-visible 显示 2px --accent 焦点环。
动效降级prefers-reduced-motion: reduce 时禁用入场动画和 hover 位移。

FR-07　无障碍

维度说明
FR-07组件满足键盘可达和读屏可达。
标题语义标题渲染为 <h3>，保证页面标题层级正确（首页大标题为 h1，卡片标题为 h3）。
区域标注标题区 role="group" aria-label="{title}"；底部区如含操作链接，链接自身携带 aria-label。
标签可达技术标签为视觉辅助，aria-hidden="true"，不进入 Tab 序列。
对比度标签文字色 --accent 与背景对比度 ≥ 3:1（大字/UI 组件阈值）。

FR-08　Props 接口汇总

Prop类型必填默认值说明
titlestring是—卡片标题，渲染为 h3
techTagsstring[]否[]技术标签数组，渲染在标题区第二行
childrenReactNode否—内容区内容
footerReactNode否—底部区内容；不传则不渲染底部区
span'3'|'4'|'6'|'8'|'12'否'4'Bento 网格占位宽度
classNamestring否—附加类名，用于调用方覆盖样式

5. 共享规则与异常

5.1 样式作用域

  • 组件样式类名统一使用 cl- 前缀（CardLayout），写在 src/components/CardLayout.css 中，由组件文件 import 引入。
  • 网格占位类 bento-span-* 复用 Home.css 中既有定义，不重复声明。
  • 颜色、字体等 CSS 变量引用首页既有的 --home-* 或全局 --accent 等变量，不硬编码色值。

5.2 异常与降级

场景处理
title 未传组件抛出控制台警告 CardLayout requires a title prop，渲染占位文本"未命名卡片"。
techTags 为空数组 / undefined不渲染标签容器 DOM；标题区仅显示标题行。
techTags 含空字符串项渲染前过滤掉空字符串项；过滤后为空则同上降级。
children 为 null内容区渲染空容器（保持三段结构），高度为 padding 值。
footer 为 null / undefined不渲染底部区 DOM，卡片仅两段。
span 传入非法值降级为 bento-span-4，控制台警告。
不支持 backdrop-filter降级为实色背景（@supports 回退，与既有 bento-card 一致）。
prefers-reduced-motion: reduce禁用入场动画、hover 位移、标签 hover 动效。

5.3 文件落位

文件路径职责
组件逻辑src/components/CardLayout.jsxReact 函数组件，props 解析与三段结构渲染
组件样式src/components/CardLayout.csscl- 前缀样式，玻璃拟态、标签、响应式
首页调用src/pages/Home.jsx在 Bento 网格中引入并使用 <CardLayout> 渲染新卡片

5.4 基线对比

对比 src/docs/project-features.md 第 3.1 节首页基线：

  • 新增：首页 Bento 网格中出现由 CardLayout 组件渲染的卡片（三段结构 + 标题区技术标签）。
  • 修改：Home.jsx 新增 import CardLayout 及对应 JSX 调用；Home.css 无修改（组件样式独立）。
  • 删除：无（既有卡片结构保持不变）。

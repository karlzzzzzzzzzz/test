|------|------|-----------|----------|
| 路由（`App.jsx`） | 访问 `#/sokoban` | `lazy(() => import('./pages/Sokoban'))` 独立分包，Suspense 回退「加载中…」 | 分包加载失败由 React 边界沿用既有 loading 文案，不阻塞其他路由 |
| 首页入口（`Home.jsx` ENTRIES） | 点击「开始挑战 →」 | 新增第 16 项：`to:'/sokoban'`、`span:'3'`、`techTags:['DOM','React Hooks','Puzzle']`，描述写明「12 关 / 三档 120·150·180 秒 / 可撤销重开」；沿用 `home-entry-clicks` 计数 | 字段缺失沿用 `CardLayout` 既有降级；不改既有 15 项 |
| 首页统计（`Home.jsx`） | 进入视口 | 模块数继续由 `ENTRIES.length` 驱动（变为 16），无手写数字 | `AnimatedNumber` 在 reduced-motion 下直接显示终值 |
| 技术文档中心（`registry.js`） | 打开 `/docs/sokoban-game` | 新增 `sokoban-game.md` 的 `?raw` 导入与 docs 条目（slug/title/summary/date/tags/readTime/content） | slug 不存在时 `DocView` 既有「文档未找到」空态 |
| 引擎 · 地图解析（`SokobanEngine.js`） | `start(levelIndex)` | 解析 `#` 墙、`.` 目标、`$` 箱子、`*` 箱在目标、`@` 玩家、`+` 玩家在目标；行宽一致、箱子数=目标数、玩家唯一 | 关卡索引越界回退第 1 关；地图非法抛出并保留 `start` 态 |
| 引擎 · 移动/推箱 | 方向键 / 相邻格点按 / 滑动 | 玩家向四方向走一步；目标格是箱子时，箱子后一格必须为空地，否则整步无效；有效步 `moves+1`，推箱额外 `pushes+1` | 撞墙、推双重箱、越界时返回 `blocked`，不增加步数 |
| 引擎 · 目标判定 | 每次有效移动后 | 所有箱子位于目标点 → `state='over'`，触发 `onGameOver(score, elapsed, 'win')` | 箱子离开目标点不触发结算，仅更新 HUD |
| 引擎 · 撤销 | 点击「撤销」 | 栈内保存每次有效移动前的 `{player, boxes, moves, pushes}`；恢复后步数与推箱数一并回退；历史上限 200 步 | 空栈或非 playing 时返回 false，不改变状态；无次数限制 |
| 引擎 · 重开 | 点击「重开本关」 | 按当前关卡初始地图重建，步数/推箱/历史清零，计时清零并重新开始 | 非 playing/paused 时不响应 |
| 引擎 · 计时 | 页面每 200ms `tick()` | 首次有效移动启动计时；`elapsedBase + resumeAt` 双字段；达到 `limitSec`（入门 120 / 进阶 150 / 专家 180）→ `failed` | 未开始移动不超时；切后台冻结不计时 |
| 引擎 · 计分 | 通关时 | `max(100, baseScore − max(0, moves−par)×8 − floor(elapsed)×2)`；base 500/800/1200，par 为求解器最小步数（3/5/6/8/9/10/13/13/19/23/26/27） | 分数下限 100；失败不计分 |
| 页面 · 四态 | start / playing / paused / over / failed | 四态遮罩 + HUD；start 展示 12 关选择与每关最佳；over 展示步数/推箱/用时/得分/最佳/通关寄语；failed 展示超时 | 引擎异常 → 「棋盘加载失败，请重试」+ 重试按钮，不进入 playing |
| 页面 · 触控 | 点按、方向键按钮、滑动 | 点按与玩家正交相邻的格子即向该方向移动；方向键区四个按钮直接移动；棋盘滑动位移 ≥24px 且主轴占比 >70% 判定方向 | 点按非相邻格、滑动不足、斜向滑动一律忽略并播报「只能移动到相邻格」 |
| 页面 · 键盘与读屏 | Tab / 方向键 / Enter·Space | 棋盘 `role=grid`、行 `role=row`、格 `role=gridcell`；roving tabindex 仅玩家所在格 `tabIndex=0`，移动后焦点跟随玩家；`aria-live=polite` 播报移动/推箱/撞墙/撤销/胜负；计时器 `aria-live=off` | 焦点在格子按钮上时方向键由棋盘接管并 `preventDefault`，不触发页面滚动 |
| 页面 · 暂停 | 手动暂停 / 切后台 / 失焦 | `visibilitychange` + `window.blur` 双路 + `pausedByVisibilityRef` 去重；仅 playing 生效；暂停冻结计时并禁用棋盘（`pointer-events:none` + `aria-hidden`） | 恢复手动点击；`document.hidden` 时拒绝恢复 |
| 页面 · 通关寄语（外部 API） | 通关后自动 | `GET https://v1.hitokoto.cn/?encode=json&charset=utf-8`，`AbortController` 3 秒超时；`normalizeQuote` 校验 `hitokoto` 非空、截断 80 字、`from` 截断 30 字 | 非 2xx / 超时 / 字段非法 → 降级到 8 条本地句子池（按关卡确定性选句），并标记来源「本地句子池」 |
| 存储 · 最佳（`game-sokoban-best-v1`） | 通关 | `{ v:1, best:{ [levelId]: {score, moves, time} }, updatedAt }`；仅更高分覆盖 | JSON 损坏/版本不符回退空对象；配额满 → 仅内存 + 结算页提示 |

## 5. 状态说明

- **加载**：`/sokoban` 分包加载期间显示「加载中…」；通关寄语请求期间显示「正在生成通关寄语…」。
- **空**：start 态显示 12 关列表，每关无记录时显示「暂无记录」。
- **错误**：
  1. 引擎构造异常 → 错误屏 + 重试。
  2. 一言 API 超时/非 2xx/字段非法 → 本地句子池降级，不显示错误弹窗。
  3. localStorage 不可用/配额满 → 游戏继续，结算页提示「本局成绩未保存」。
- **边界情况（≥4）**：
  1. 箱子被推到墙角且不在目标点，形成死局 → 玩家可撤销或重开。
  2. 撤销栈为空 / 连点撤销 → 无副作用。
  3. 倒计时未启动时暂停、切后台 → 不累计时间。
  4. 最后一关通关 → 显示「全部通关」，无「下一关」按钮。
  5. 关卡索引非法或地图行宽不一致 → 回退第 1 关 / 保持 start 态。
  6. 滑动与点按在同一帧内连续触发 → 以首个有效移动为准，后续方向若无效则忽略。

## 6. 非功能需求

- **（约束卡① 撤销/回退）** 撤销无次数限制，但必须完整回退 `player/boxes/moves/pushes` 四项，禁止只回退位置导致步数虚高；历史上限 200 步，超出丢弃最早记录。
- **（约束卡② 移动端）** 地图最多 6 列；320px 下棋盘可用宽度 = 320 − 页面内边距 24 − 棋盘内边距 20 − 列间距 30 = 246px，单格 ≥41px；方向键按钮与动作按钮高度 ≥44px；页面 `min-height:100svh`、`overflow-x:hidden`、`touch-action:manipulation`；`prefers-reduced-motion` 关闭位移与过渡。
- **（约束卡③ 外部 API 与失败降级）** 仅调用一言 `v1.hitokoto.cn`，3 秒超时，无 Key、单次请求；失败降级 8 条本地句子池并按日缓存，避免同日反复请求失败接口。
- **性能**：引擎纯逻辑，单次移动 O(1)（箱子判定用 Set），12 关地图 ≤6×8；页面 DOM ≤48 格，无 Canvas/无 rAF 常驻。
- **兼容**：HashRouter 深链 `#/sokoban` 可直达；键盘与触屏语义一致；不新增第三方依赖。
- **埋点**：`game-sokoban-stats-v1` 仅本地累计，不上报远端。

## 7. 验收标准

1. **Given** 首页已加载，**When** 滚动到作品入口，**Then** 看到第 16 张「推箱子」卡，点击进入 `#/sokoban`，统计条模块数显示 16。
2. **Given** 打开 `/docs`，**When** 点击「推箱子」文档卡，**Then** 进入 `/docs/sokoban-game` 且正文渲染成功。
3. **Given** 开始第 1 关，**When** 玩家向上、向右、向下移动并推动箱子，**Then** 箱子落到目标点、出现通关结算、步数与推箱数为 3/1。
4. **Given** 箱子后方是墙或另一个箱子，**When** 玩家尝试推动，**Then** 整步无效、步数不变、`aria-live` 播报「前方被挡住」。
5. **Given** 一局进行中，**When** 点击撤销，**Then** 玩家与箱子回到上一步，步数与推箱数同步回退，焦点跟随玩家。
6. **Given** 一局进行中，**When** 点击重开，**Then** 地图、步数、推箱、历史与计时全部重置。
7. **Given** 单关倒计时结束，**When** 达到 120/150/180 秒，**Then** 进入 failed 屏，得分 0，可重试本关（异常）。
8. **Given** 游戏进行中，**When** 切到后台或窗口失焦，**Then** 自动暂停并冻结计时，恢复后继续；双路事件不重复暂停（异常）。
9. **Given** 一言接口超时或返回非法 JSON，**When** 通关，**Then** 显示本地句子池寄语且游戏流程不中断；同日不再重复请求（异常）。
10. **Given** 任意一关通关，**When** 刷新页面再进入 start 屏，**Then** 该关最佳成绩仍在；localStorage 损坏时回退为「暂无记录」且不报错（异常）。
11. **Given** 320/375/414/480/600/768/820/1024 九档宽度，**When** 运行 `npm run audit:mobile -- --url ...#/sokoban`，**Then** 0 横向溢出、0 越界、0 热区 <40px、0 字号 <12px。
12. **Given** 仅键盘操作，**When** 用方向键在棋盘移动，**Then** 焦点跟随玩家格、方向键不滚动页面、`aria-live` 播报移动与推箱结果。

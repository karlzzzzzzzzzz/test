# 生命游戏（Game of Life）需求文档

> 需求类型：新增功能（新增一个小游戏）· 规模：大型 · 目标路由：`/life-game`
> 关联页面：首页作品入口、技术文档中心
> 实现日期：2026-11-19 · 小游戏上线顺序：第 22 款 · 首页作品入口：第 27 张卡

## 1. 需求背景与目标

首页作品入口已有 26 张卡片，覆盖棋类、解谜、动作与消除，但缺少「没有玩家操作也会自己演化」的模拟类玩法。新增第 22 款小游戏**生命游戏（Game of Life）**，用康威元胞自动机的 B3/S23 规则补齐模拟观察类体验，并复用既有工程约定（引擎与页面壳解耦、六屏状态机、双路自动暂停、键盘可达、番茄钟联动）。

目标：

1. 完整实现 40×24 网格上的 B3/S23 演化，支持环绕 / 固定两种边界。
2. 内置 7 种经典图案（滑翔机、闪烁灯、静物方块、脉冲星、高斯帕滑翔机枪、橡果、R 五连方），并支持 RLE 文本 / 文件导入。
3. 提供四档演化速度与手动单步，允许在暂停时点击或拖动编辑细胞。
4. RLE 导入覆盖加载中 / 空图案 / 解析失败 / 导入成功四态，失败不破坏当前盘面。
5. 切到后台或窗口失焦时自动暂停，回来后保持暂停，不偷偷推进代数。
6. 记录累计演化统计，并与番茄钟会话语义打通。

## 3. 页面结构

1. **顶部栏**：返回首页链接（≥44px 热区）、标题「生命游戏」、当前速度徽标。
2. **开始屏**：规则说明 → 7 种图案卡片（名称 + 一句说明）→ 四档速度（慢速 / 常速 / 快速 / 极速）→ 环绕边界开关 →「开始演化」→「导入 RLE 图案」→ 累计统计 → 操作说明。
3. **对局 HUD**：代数、活细胞、本代出生、本代死亡、最高人口、用时。
4. **棋盘**：Canvas 2D 绘制 40×24 网格，活细胞青色（少量琥珀色点缀）；支持指针点击与按住拖动放置 / 移除细胞；`role="img"` + 动态 aria-label。
5. **控制区**：暂停 / 继续、单步、随机、清空、图案下拉、导入 RLE、返回菜单；速度 chips 与环绕开关。
6. **遮罩**：暂停（区分手动 / 自动暂停及原因，含继续、单步、结束观察、返回菜单）；结束（灭绝 / 主动结束 + 代数、最高人口、出生、死亡、用时）。
7. **RLE 导入面板**：文件选择、文本粘贴、解析按钮、状态提示（加载中 / 空 / 错误 / 成功）。

## 4. 功能明细

| 模块 | 触发 | 行为 | 边界/异常 |
| --- | --- | --- | --- |
| `LifeEngine.js` 邻居计数 | 每代演化 | 统计 8 邻居；`wrap=true` 时上下左右与对角环绕，`false` 时越界视为死 | 角格与边格不能重复计数 |
| `LifeEngine.js` 演化规则 | `step()` | B3/S23：活细胞 2/3 邻居存活，死细胞恰 3 邻居复活；统计本代出生 / 死亡 | 非 playing / paused 状态返回 false |
| `LifeEngine.js` 灭绝判定 | 演化后人口为 0 | 停止计时，状态置 `over`，回调 `onGameOver({result:'extinct'})` | 灭绝后不可继续 step / 编辑 / 清空 |
| `LifeEngine.js` 手动结束 | `stop()` | 进入 `over`，回调 `onGameOver({result:'stopped'})`，保留当前人口 | 未开局或已结束返回 false |
| `LifeEngine.js` 内置图案 | `start(preset)` / `loadPreset` | 从 RLE 解析并按网格居中放置，代数归零，重算人口 / 最高人口 | 非法 key 回退默认滑翔机 |
| `LifeEngine.js` 自定义图案 | `loadCells(cells)` | 居中放置导入细胞，标记 `imported=true`，代数归零 | 空数组或超出 40×24 时返回 `{ok:false, reason}` |
| `LifeEngine.js` 编辑 | `toggleCell(index)` | 切换单格生死并更新人口 / 最高人口 | 非 playing / paused 返回 null；越界返回 null |
| `LifeEngine.js` 清空 / 随机 | `clear()` / `randomize(density)` | 清空或按密度重建盘面，代数归零 | 开局前或结束后拒绝执行 |
| `LifeEngine.js` 速度 / 边界 | `setSpeed(key)` / `setWrap(bool)` | 更新快照中的速度与边界，非法速度返回 false | 运行中切换立即生效，不重置盘面 |
| `parseRLE` 解析 | 导入文本 / 文件 | 解析 `x = N, y = N` 头、`b/o/$/!`、数字重复与注释行 | 缺头、非法字符、超出声明宽高抛错；空图案返回空 cells |
| `Life.jsx` 开局 | 点「开始演化」 | 载入选中图案，状态 playing，按速度启动定时器，累计 runs +1 | 图案缺省用滑翔机；速度 / 边界取自开始屏 |
| `Life.jsx` 暂停 / 继续 | 按钮 / 空格 / Esc | playing → paused；paused → playing；切换时重建定时器 | 结束态忽略 |
| `Life.jsx` 单步 | 按钮 / N | 运行中先暂停，再推进一代并播报代数与人口 | 结束态返回；灭绝时直接进入结束屏 |
| `Life.jsx` 画布编辑 | 指针按下 / 拖动 | 运行中先暂停；按坐标换算行列并切换细胞，拖动时同格只处理一次 | 越界坐标忽略；结束态不可编辑 |
| `Life.jsx` 自动暂停（约束卡①） | `visibilitychange(hidden)` + `window blur` | 双路去重，仅 playing 时暂停一次并记录原因，恢复需手动继续 | 暂停时先 flush 统计；回页不自动恢复 |
| `Life.jsx` RLE 导入（约束卡②） | 选文件 / 粘贴文本 / 解析 | 文件读取与解析期间显示加载态；成功载入并进入暂停编辑；无活细胞显示空态；语法错误显示错误原因 | 不破坏当前盘面；错误 / 空态保留重试入口 |
| `Life.jsx` 埋点（约束卡③） | 每代 / 开局 / 结束 / 导入 / 换速 | 更新 `game-life-stats-v1`：runs/generations/maxPopulation/maxGeneration/extinctions/randomizes/imports/importErrors/speedChanges | 脏标记 + 1s 防抖 + pagehide 落盘；存储异常静默降级 |
| `Life.jsx` 番茄钟联动 | 结束观察 / 灭绝且用时 ≥120s | 追加 `pomodoro-sessions-v1`：`{ startTs, endTs, durSec, game:'life', win, level }` | 不足 120s 不写；同一局只结算一次 |

## 5. 状态说明

- **加载**：路由懒加载期间显示全局「加载中…」；RLE 文件读取 / 解析期间显示「加载中」状态，解析按钮禁用。
- **成功**：导入成功显示绿色「导入成功：N 个活细胞」，盘面替换并进入暂停状态，便于继续编辑或播放。
- **空**：尚未开始演化时开始屏统计显示 0；RLE 内容没有活细胞时显示琥珀色「空图案」提示，不替换盘面。
- **错误**：RLE 缺少头信息、含非法字符、超出声明宽高或超出棋盘时显示红色错误原因，不替换盘面；`localStorage` 不可用时统计仅在内存累计，不阻塞玩法。
- **暂停**：手动暂停与自动暂停均显示遮罩；自动暂停额外说明「切到后台或窗口失焦时自动暂停，回来后不会继续演化」。
- **结束**：人口归零显示「宇宙归于寂静」，主动结束显示「观察结束」，两者都展示代数、最高人口、累计出生 / 死亡与用时。

## 6. 非功能与约束

- **性能**：单代最多 960 格 × 8 邻居，纯 `Uint8Array` 计算；Canvas 固定逻辑尺寸 640×384，按容器缩放；极速档 60ms/代仍为单次同步计算，不引入 Worker。
- **移动端**：画布 `width:100%` 自适应，320px 视口不横向溢出；所有按钮 ≥40px、遮罩按钮 ≥44px；最小字号 0.75rem（12px）；画布 `touch-action: none` 避免拖动页面。
- **兼容**：无后端；`min-height: 100vh`；`prefers-reduced-motion` 下关闭按钮过渡；`file.text()` 不可用时显示错误态并提示改用粘贴。
- **约束卡①（切后台 / 失焦行为）**：`visibilitychange(hidden)` 与 `window blur` 双路调用同一暂停函数，依靠 `state === 'playing'` 去重；暂停时立即冲刷统计，恢复后保持 paused，必须手动继续。
- **约束卡②（加载 / 空 / 错误三态）**：RLE 导入显式建模 `loading / empty / error / ready`；文件读取与解析异步等待，保证加载态可见；空与错误都不修改当前盘面。
- **约束卡③（埋点统计关键行为）**：`game-life-stats-v1` 记录开局、代数、最高人口、最高代数、灭绝、随机、导入、导入失败、换速；脏标记 + 1s 防抖 + `pagehide` 落盘，读取逐字段归一。

## 7. 验收标准

1. **Given** 进入 `/life-game`，**When** 页面加载完成，**Then** 显示开始屏、7 种图案卡片、四档速度与环绕开关，且无 console 错误。
2. **Given** 选择滑翔机并开始，**When** 进入对局，**Then** 画布出现 5 个活细胞，HUD 显示代数 0、人口 5、最高人口 5。
3. **Given** 闪烁灯图案，**When** 连续单步两次，**Then** 盘面从横向变为纵向再恢复横向，代数显示 2。
4. **Given** 滑翔机图案，**When** 以常速演化 4 代，**Then** 活细胞整体向右下各移动一格，人口仍为 5。
5. **Given** 对局正在播放，**When** 点击画布中的空格，**Then** 自动暂停并把该格切换为活细胞，aria-live 播报行列与放置结果。
6. **Given** 暂停状态，**When** 按住指针在画布上拖动，**Then** 经过的格子依次切换，同一格在本次拖动中不会反复切换。
7. **Given** 对局正在播放，**When** 切换速度档位，**Then** 新节奏立即生效且不重置代数与盘面。
8. **Given** 对局正在播放，**When** 切换到其他标签页或窗口失焦，**Then** 只自动暂停一次；回到页面后仍为暂停态，需手动继续。
9. **Given** RLE 文本正确且包含活细胞，**When** 点击「解析文本」，**Then** 先显示加载中，随后显示导入成功并载入居中的自定义图案。
10. **Given** RLE 只有死细胞（如全 `b`），**When** 解析，**Then** 显示「空图案」状态且当前盘面不变（异常）。
11. **Given** RLE 缺少 `x/y` 头或含非法字符，**When** 解析，**Then** 显示具体错误原因、`importErrors` +1，且盘面不变（异常）。
12. **Given** 导入图案超过 40×24，**When** 解析成功但载入，**Then** 返回「超出棋盘」错误并保留原盘面（异常）。
13. **Given** 所有细胞在演化中死亡，**When** 进入下一代，**Then** 状态变为 over，显示「宇宙归于寂静」并停止计时。
14. **Given** 一局有效演化 ≥120s，**When** 主动结束或细胞灭绝，**Then** `pomodoro-sessions-v1` 追加一条 `game:'life'` 的记录，同一局不重复写入。
15. **Given** 刷新页面或关闭标签，**When** 触发 `pagehide`，**Then** 累计统计已写入 `game-life-stats-v1`；再次进入开始屏能看到累计代数与历史最高人口。

# 汉诺塔（Tower of Hanoi）需求文档

> 需求类型：新增功能（新增一个小游戏）· 规模：大型 · 目标路由：`/hanoi-game`
> 关联页面：首页作品入口、技术文档中心
> 实现日期：2026-11-20 · 小游戏上线顺序：第 23 款 · 首页作品入口：第 28 张卡

## 1. 需求背景与目标

首页作品入口已有 27 张卡片，棋类、解谜、动作、消除与模拟均有覆盖，但缺少以「递归 / 最优步数」为核心的经典益智玩法。新增第 23 款小游戏**汉诺塔**，补齐递归思维与最少步数挑战，并复用既有工程约定（引擎与页面壳解耦、六屏状态机、双路自动暂停、键盘可达、番茄钟联动）。

目标：

1. 实现三柱、3~8 盘的完整汉诺塔规则：每次移动顶部圆盘，大盘不能压小盘。
2. 提供 3 / 4 / 5 / 6 / 7 / 8 盘六档难度，显示理论最少步数 `2^n - 1` 与个人最佳。
3. 支持点击 / 触控整根柱子完成「拿起 → 放下」，并支持键盘 1 / 2 / 3。
4. 当前进度本地持久化：容量 ≤4096 字符、24 小时 TTL、通关 / 重开 / 放弃即清理。
5. 移动端 320px 窄屏不横向溢出，所有热区 ≥44px，不依赖拖拽。
6. 记录完成局数、累计步数、失误、撤销与各盘数最佳步数，并与番茄钟会话打通。

## 3. 页面结构

1. **顶部栏**：返回首页链接（≥44px 热区）、标题「汉诺塔」、当前盘数徽标。
2. **开始屏**：规则说明 →「继续上次」卡片（有合法存档时）→ 3~8 盘选择（含最少步数与个人最佳）→「开始挑战」→ 累计统计 → 操作说明。
3. **对局 HUD**：步数、最少步数、失误、撤销、用时、盘数。
4. **棋盘**：三根整列可点击的柱子按钮；柱内圆盘自下而上由大到小；选中柱高亮并抬起顶部圆盘；每根柱子有 `aria-label` 与 `aria-pressed`。
5. **遮罩**：暂停（区分手动 / 自动，含继续、撤销一步、重开本局、结束观察、返回菜单）。
6. **结束屏**：完成 / 观察结束 + 实际步数、最少步数、失误、撤销、用时、盘数；使用过撤销时提示不计入最佳。
7. **状态提示**：`aria-live` 播报选柱、移动、非法移动原因、撤销、通关与自动暂停。

## 4. 功能明细

| 模块 | 触发 | 行为 | 边界/异常 |
| --- | --- | --- | --- |
| `HanoiEngine.js` 初始化 | `start(disks)` | 校验 3~8 盘，生成第 1 柱 `[n..1]`，其余为空，状态 playing | 非法盘数回退 4 盘 |
| `HanoiEngine.js` 最少步数 | `minMoves(n)` | 返回 `2^n - 1`，用于 HUD 与结算 | n 超出 3~8 不用于开局 |
| `HanoiEngine.js` 选择柱子 | `select(peg)` | 空选择时选中有盘子的柱；再点同柱取消；再点他柱尝试移动 | 空柱返回「该柱没有圆盘」 |
| `HanoiEngine.js` 移动 | `move(from,to)` | 校验顶部圆盘，合法则移动、步数 +1、记录历史 | 大盘压小盘计 1 次失误并保持柱面 |
| `HanoiEngine.js` 通关 | 移动后 C 柱满 | 停止计时，状态 over，回调 `onGameOver({result:'win'})` | 通关后拒绝移动 / 撤销 / 选择 |
| `HanoiEngine.js` 撤销 | `undo()` | 回退最近一步，步数 -1、撤销 +1，标记 assisted | 无历史返回失败；存档恢复后历史为空 |
| `HanoiEngine.js` 手动结束 | `stop()` | 进入 over，回调 `result:'stopped'`，保留当前步数 | 开局前 / 已结束返回 false |
| `HanoiEngine.js` 存档恢复 | `restore(save)` | 校验盘数、柱面排列、计数后恢复为 paused | 重复盘、倒序、非 3 柱、负计数均拒绝 |
| `Hanoi.jsx` 开始 / 重开 | 按钮 | 清旧存档、启动新局、plays +1、重置会话计时 | 重开前若有步数，按 stopped 计入累计 |
| `Hanoi.jsx` 点击柱子 | 指针 / 触控 | 整根柱子为按钮，点按完成选择或移动；移动与键盘语义一致 | 非法移动播报原因，不改变柱面 |
| `Hanoi.jsx` 键盘 | 1/2/3、Space、U、Esc | 数字键选柱 / 移动，空格暂停继续，U 撤销，Esc 暂停 | 输入框 / 文本域内不拦截 |
| `Hanoi.jsx` 暂停 | 按钮 / 快捷键 | playing ⇄ paused，暂停时停表，遮罩提供继续、撤销、重开、结束、菜单 | 结束态忽略 |
| `Hanoi.jsx` 自动暂停 | `visibilitychange(hidden)` + `blur` | 双路去重，仅 playing 暂停一次；立即写存档与统计 | 回来保持暂停，不自动继续 |
| `Hanoi.jsx` 进度存档（约束卡①） | 每次移动 / 暂停 / pagehide | 写 `game-hanoi-save-v1`：盘数、柱面、步数、失误、撤销、用时、ts | JSON >4096 字符不写；24h TTL；坏档自动删除 |
| `Hanoi.jsx` 继续上次 | 开始屏「继续」 | 校验存档后 `restore`，进入 paused，手动继续后开始计时 | 存档非法时提示并清理，不阻塞新局 |
| `Hanoi.jsx` 结算统计 | 通关 / 结束 | 更新 `game-hanoi-stats-v1`：plays/wins/totalMoves/mistakes/undos/bestMoves | 使用撤销的局不计入最佳；存储失败静默 |
| `Hanoi.jsx` 番茄钟 | 通关 / 结束且 ≥120s | 追加 `pomodoro-sessions-v1`（`game:'hanoi'`、win、level） | 不足 120s 不写；同一局只结算一次 |
| `Hanoi.jsx` 移动端适配（约束卡③） | 窄屏 / 触控 | 三柱等宽、整柱可点、圆盘按百分比缩放；320px 不横向滚动 | 按钮 ≥44px；8 盘仍能完整堆叠 |

## 5. 状态说明

- **加载**：路由懒加载显示全局「加载中…」；开始屏读取本地存档与统计为同步操作，无额外骨架屏。
- **空**：无存档时隐藏「继续上次」；无个人最佳时显示「尚无记录」；统计初始为 0。
- **错误**：存档 JSON 损坏、TTL 过期、柱面非法时自动删除并安静回到开始屏；`localStorage` 不可用时仅内存统计，不阻塞玩法。
- **进行中**：选中柱高亮 + 顶部圆盘抬起；非法移动只播报原因并累计失误，不改变柱面。
- **暂停**：手动 / 自动暂停均显示遮罩；自动暂停说明切后台或失焦不会继续计时。
- **结束**：通关显示「完成！」与步数对比；主动结束显示「观察结束」，不保留进度。

## 6. 非功能与约束

- **性能**：柱面为 3 个长度 ≤8 的数组，移动与校验 O(1)；页面定时器仅 500ms 刷新用时，无重计算。
- **移动端**：三柱 `grid` 等宽；圆盘宽度按盘号百分比计算（42%~96%），高度 22px / 20px / 18px 三档；整根柱子为按钮，最小高度 300px / 260px / 230px；`touch-action: manipulation`；320px 不横向溢出。
- **兼容**：无后端；`min-height: 100vh`；`prefers-reduced-motion` 下关闭过渡；按钮统一 `:focus-visible` 焦点环。
- **约束卡①（localStorage 持久化，含容量与清理）**：`game-hanoi-save-v1` 单条 JSON ≤4096 字符，24h TTL，读取时校验 `v=1`、盘数 3~8、柱面为 1..n 的合法排列、计数非负；通关、重开、放弃、结束观察即删除；`pagehide` / 卸载时冲刷。
- **约束卡②（与基线描述联动修正）**：同步更新 1.4 路由、3.1 卡片数与统计、3.5 文档中心、第 3 节新小节、第 4 节两个存储键与番茄钟 `game` 取值，避免计数或存储清单漂移。
- **约束卡③（移动端触控与窄屏）**：不使用拖拽，整柱点按即可完成拿放；三档断点（640 / 360）重排 HUD 与盘数卡片；所有交互元素 ≥44px，字号 ≥0.75rem。

## 7. 验收标准

1. **Given** 进入 `/hanoi-game`，**When** 页面加载完成，**Then** 显示开始屏、6 档盘数与规则说明，无 console 错误。
2. **Given** 选择 4 盘并开始，**When** 进入对局，**Then** A 柱按 4→3→2→1 自下而上排列，HUD 显示步数 0、最少 15。
3. **Given** 对局中，**When** 点击 A 柱再点击 B 柱，**Then** 1 号盘移动到 B 柱，步数变为 1，A 柱顶部变为 2 号盘。
4. **Given** B 柱顶部为 1 号盘，**When** 点击 A 柱再点击 B 柱，**Then** 提示「大盘不能放在小盘上」，失误 +1，柱面不变。
5. **Given** 已选中 A 柱，**When** 再次点击 A 柱，**Then** 取消选择，不产生移动与失误。
6. **Given** 已移动一步，**When** 点击撤销或按 U，**Then** 圆盘回到 A 柱，步数回退到 0，撤销数 +1。
7. **Given** 3 盘开局，**When** 按最优解完成 7 步，**Then** 状态变为 over，显示「完成！」且「正好用最少步数完成」。
8. **Given** 对局正在计时，**When** 暂停，**Then** 计时停止；恢复后继续累计，暂停期间不能移动。
9. **Given** 对局进行中，**When** 切换到其他标签页或窗口失焦，**Then** 只自动暂停一次并写入存档，回到页面保持暂停。
10. **Given** 已有步数，**When** 刷新页面后重新进入，**Then** 开始屏出现「继续上次」，点击后恢复到暂停态，步数与用时正确。
11. **Given** 存档超过 24h，**When** 进入开始屏，**Then** 不显示「继续上次」，存档被清理（异常）。
12. **Given** 存档柱面重复或倒序，**When** 读取，**Then** 判定为坏档并删除，不阻塞新局（异常）。
13. **Given** 8 盘开局，**When** 在 320px 视口操作，**Then** 三柱与圆盘完整显示、无横向滚动，整柱可点且按钮 ≥44px。
14. **Given** 完成一局且未使用撤销，**When** 结算，**Then** 对应盘数最佳步数取本次与历史较小值；使用过撤销则不更新最佳。
15. **Given** 一局有效时长 ≥120s，**When** 通关或主动结束，**Then** `pomodoro-sessions-v1` 追加一条 `game:'hanoi'`，同一局不重复写入。

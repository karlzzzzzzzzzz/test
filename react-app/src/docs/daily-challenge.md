## 1. 背景与目标

首页目前有 14 张作品入口卡，但用户进入首页后无法快速决定「今天玩哪一个」。新增「今日游戏挑战」区块：按日期确定性从 11 款可玩小游戏中选出一款，展示规则、难度与时长，并给出直达入口；同时通过一言（hitokoto）API 提供一句「今日一句」，失败时降级到本地句子池，保证区块在任何网络状态下都完整可用。

**目标（可衡量）**：

- 首页新增 1 个顶级区块，覆盖全部 11 款可玩小游戏（`/game`、`/2048`、`/tetris`、`/snake`、`/breakout`、`/memory`、`/whack`、`/puzzle`、`/lightsout`、`/connect4`、`/lianliankan`）。
- 同一自然日多次打开（含刷新、重新进入路由）选中的游戏不变；连续两个自然日选中的游戏不相同。
- 「今日一句」请求超时上限 10s；接口失败（超时 / 非 2xx / 字段非法）时 100% 降级到本地句子，区块不出现空白或不可用按钮。
- 320 / 360 / 375 / 414 / 480 / 600 / 768 / 820 / 1024 九档宽度横向溢出为 0，可点击热区 ≥40px，可见字号 ≥12px，首页保持 `min-height:100svh`。

## 4. 功能点明细

| 模块 | 交互 | 规则/逻辑 | 异常处理 |
| --- | --- | --- | --- |
| 首页挂载（`Home.jsx`） | 滚动浏览 | 在作品入口 `ENTRIES.map` 之后、`<footer className="bento-card bento-stats">` 之前插入区块标题与 `<DailyChallenge />` | 组件渲染异常不影响其余区块；不新增 Suspense 边界 |
| 今日游戏计算（`src/api/dailyChallenge.js`） | 自动 | `pickDailyChallenge(dateKey)`：以本地日期 `YYYY-MM-DD` 取天数序号 `d`，索引 `(d + year*7) % 11`；同一日期恒定，连续两天索引差 1 故不重复 | 日期非法 → 返回 `null`，卡片走空态 |
| 游戏元信息 | 观看 | 展示游戏名、规则一句话、难度（简单/中等/困难）、预计时长 | 字段缺失时该行不渲染，不显示 `undefined` |
| 开始挑战 CTA | 点按 / Enter / Space | `Link` 跳到该游戏既有路由；点击后写入当日「已挑战」标记，状态文案变为「今日已挑战」 | 空态（无可用游戏）不渲染 CTA；存储不可用时仅内存态生效 |
| 今日状态 | 观看 | `daily-challenge-open` 记录 `{ v:1, date, ts }`，仅当 `date` 等于今日时显示「今日已挑战」，跨日自动回到「今日尚未开始」 | JSON 损坏 / 非 v1 / 日期不符 → 视为未挑战 |
| 名言拉取（`DailyChallenge.jsx`） | 自动 | `GET https://v1.hitokoto.cn/?encode=json&charset=utf-8&_=<ts>`，`AbortController` + 10s 超时 | 非 2xx、超时、JSON 解析失败 → 降级分支 |
| 名言字段校验 | 自动 | `normalizeQuote` 校验 `hitokoto` 为非空字符串，超长截断到 80 字符并补「…」；`from` 截断到 30 字符，缺失显示「一言」 | 字段类型非法 / 空串 → 视为失败并降级 |
| 按日缓存 | 自动 | 成功或降级结果写入 `daily-challenge-quote`（`date` + `text` + `source` + `fallback`），同日再次进入直接读缓存，不再发请求 | 缓存损坏 / 日期不符 → 忽略并重新请求；写入失败静默忽略 |
| 本地降级句子池 | 自动 | `FALLBACK_QUOTES` 共 8 条，按日期序号 `d % 8` 确定性选句 | 池为空（实现约束下不会发生）→ 显示「今日一句暂不可用」纯文本 |
| 重试 | 点按 / Enter / Space | 仅降级态显示「重试」按钮，点击后清空当前句、重新请求并进入 loading | 重试期间按钮 `disabled` + `aria-busy`，防重复请求 |
| loading 态 | 自动 | 名言区显示「正在获取今日一句…」占位，保持区块高度不跳动 | — |
| 空态 | 自动 | 游戏注册表为空或日期非法时，卡片显示「今日暂无可用挑战」，不渲染 CTA 与状态文案 | — |
| 午夜换日 | 定时 | 每 60s 检查本地日期，变化时重算游戏、重读「已挑战」标记并重新加载名言 | 定时器暂停期间不检查，恢复时立即补一次 |
| 切后台 / 失焦暂停 | 自动 | `visibilitychange(hidden)` 与 `window.blur` 双路去重置暂停位：先到者暂停，后到者忽略；只暂停换日定时器，不中断进行中的名言请求 | 重复触发只生效一次，不会叠加 |
| 回前台恢复 | 自动 | `visibilitychange(visible)` / `window.focus` 清除暂停位并立即校准日期 | 页面仍 hidden 时 `focus` 不恢复 |
| 键盘与 aria | Tab / Enter / Space | 区块 `aria-label`；CTA 与重试按钮原生可聚焦，Space 额外映射为激活；状态与名言变化通过 `aria-live="polite"` 播报；统一 `:focus-visible` 紫色焦点环 | 读屏播报去重由 React 状态变化驱动，不重复朗读 |
| 移动端适配 | 触控 | ≥768 双列、<768 单列；卡片内边距 <480 降为 20px；文本 `overflow-wrap:anywhere` | 长句 / 超长游戏名不撑破卡片 |

## 5. 状态说明

**三态（约束卡②）**：

- **加载**：请求发出后显示占位文案「正在获取今日一句…」，`aria-live` 播报「正在获取今日一句」。
- **成功**：显示名言正文与出处；同日缓存命中时直接呈现成功态，无骨架闪烁。
- **错误**：显示本地降级句子 + 「实时名言获取失败，已使用本地句子」提示 + 「重试」按钮；`aria-live` 同步播报降级结果。

**挑战卡自身状态**：正常（有游戏）/ 空（`pickDailyChallenge` 返回 `null`）。

**边界情况（≥4）**：

1. 跨午夜：页面停留超过 00:00，60s 内完成换日并刷新名言。
2. 注册表为空或日期字符串非法：空态且无 CTA。
3. localStorage 不可用（隐私模式 / 配额满）：不抛错，状态退化为会话内内存值。
4. 存储 JSON 损坏、版本不符或日期不符：视为无缓存 / 未挑战。
5. 名言接口返回空字段、超长文本或非 JSON：降级 + 截断。
6. 重试连点：按钮 loading 期间禁用，只保留一次在途请求。
7. 快速切换标签页：暂停/恢复双路信号去重，不出现重复定时器。

## 6. 非功能需求

- **（约束卡① 外部 API 与失败降级）** 仅调用一言 `v1.hitokoto.cn`，10s 超时；失败降级到 8 条本地句子池，按日期确定性选句；降级结果同样写当日缓存，避免同一天反复请求失败接口。
- **（约束卡② 三态）** 加载 / 成功 / 错误三态均有明确视觉与 `aria-live` 文案，任何状态下区块高度不塌陷、CTA 与重试按钮不重叠。
- **（约束卡③ 键盘与 aria）** 全部交互元素热区 ≥40px，支持 Tab 聚焦与 Enter/Space 激活，焦点环 2px `#aa3bff`；区块与状态文案具备可朗读标签。
- **性能**：首页仅新增 1 次外部请求（缓存命中时为 0 次），无轮询；换日检查为 60s 轻量定时器，页面隐藏/失焦时暂停。
- **兼容**：不依赖 `ResizeObserver` 等新 API；不支持 `AbortController` 的环境下由 `Promise.race` 超时兜底降级（现代浏览器均支持，仅作防御）。
- **埋点**：本次不新增埋点事件与统计键，不写 `window.__*` 全局变量。
- **移动端（沿用项目既有质量线）**：320~1024 九档无横向溢出/越界；可点击热区 ≥40px；可见字号 ≥12px；首页 `min-height:100svh`。

## 7. 验收标准

1. **Given** 打开首页，**When** 页面渲染完成，**Then** 作品入口之后出现「03 今日游戏挑战」区块，展示游戏名、规则、难度、时长与「开始挑战」CTA，且区块双列布局在 ≥768 生效。
2. **Given** 同一自然日，**When** 刷新页面或离开后重新进入首页，**Then** 选中的游戏与「今日一句」内容一致（缓存命中，不再请求接口）。
3. **Given** 连续两个自然日，**When** 分别打开首页，**Then** 两天选中的游戏不相同。
4. **Given** 名言接口正常，**When** 请求在 10s 内返回合法 JSON，**Then** 展示名言正文与出处，并写入当日缓存。
5. **Given** 名言接口超时 / 返回 500 / 返回非法字段，**When** 请求结束，**Then** 展示本地降级句子与「已使用本地句子」提示，重试按钮可用（异常）。
6. **Given** 降级态，**When** 点击「重试」且接口恢复，**Then** 名言区回到 loading 后展示实时句子，提示与重试按钮消失。
7. **Given** 重试正在进行，**When** 再次点击重试按钮，**Then** 按钮为 disabled 且不会发出第二个请求（异常）。
8. **Given** 页面停留跨过 00:00，**When** 定时检查触发，**Then** 游戏与名言在 60s 内切换到新一天的内容，「今日已挑战」回到未挑战（异常）。
9. **Given** 标签页隐藏或窗口失焦，**When** 暂停期间到达换日时间，**Then** 定时器不触发；回到前台后立即校准并只切换一次（异常）。
10. **Given** localStorage 被禁用或写入损坏 JSON，**When** 点击「开始挑战」或读取缓存，**Then** 页面不报错，状态退化为内存值且名言仍可正常请求（异常）。
11. **Given** 键盘用户，**When** Tab 到 CTA 并按 Enter 或 Space，**Then** 跳转到对应游戏路由；`aria-live` 播报状态与名言变化；焦点环可见。
12. **Given** 320 / 375 / 768 / 1024 宽度，**When** 首页滚动到底部，**Then** 无横向滚动、卡片内容不越界、热区 ≥40px、可见字号 ≥12px，320 与 375 截图通过。

## 8. 存储变更

| 键名 | 用途 | 生命周期 |
| --- | --- | --- |
| `daily-challenge-open` | 今日是否已点击「开始挑战」，结构 `{ v:1, date:'YYYY-MM-DD', ts:number }` | 持久；跨日自动失效（按 `date` 比对） |

# 消消乐（Match 3）需求文档

> 需求类型：新增功能（新增一个小游戏）· 规模：大型 · 目标路由：`/match3`
> 关联页面：首页作品入口、技术文档中心
> 实现日期：2026-11-18 · 小游戏上线顺序：第 21 款 · 首页作品入口：第 26 张卡

## 1. 需求背景与目标

首页作品入口已有 25 张卡片，消除类只有连连看（配对消除），缺少「交换相邻方块、三连消除、连锁下落」的经典三消玩法。新增第 21 款小游戏**消消乐（Match 3）**，补齐消除类玩法谱系，并复用既有工程约定（引擎与页面壳解耦、六屏状态机、双路自动暂停、键盘可达、番茄钟联动）。

目标：

1. 完整实现 8×8 三消规则：交换相邻宝石、横竖 ≥3 同色消除、上方下落、顶部补充、连锁倍增。
2. 提供三档难度（5/6 色、25/22/18 步、1500/2200/3000 目标分），限步达标即胜利。
3. 棋盘无任何可消交换时自动重排，避免死局。
4. 局中自动存档，24 小时内可继续；通关 / 失败即清理，避免陈旧存档堆积。
5. 全程可键盘操作与读屏播报，移动端 320px 起不横向溢出。

## 3. 页面结构

1. **顶部栏**：返回首页链接（≥44px 热区）、标题「消消乐 · Match 3」。
2. **开始屏**：规则说明 → 三档难度选择（色数 / 步数 / 目标分）→「开始挑战」→「未完成对局」面板（难度、分数、剩余步数、已用时长、继续按钮；无存档时显示空态说明）→ 累计战绩与当前难度最佳分 → 操作说明。
3. **游戏主界面 HUD**：计时器、当前分 / 目标分、剩余步数（≤3 步红色警示）、难度标签、暂停/继续、重开、菜单。
4. **目标进度条**：按 `score / target` 计算宽度，达到 100% 即胜利。
5. **计分行**：交换次数、消除总数、本次得分与连锁段数、自动重排提示。
6. **棋盘**：8×8 CSS Grid，每格一个 `button[role=gridcell]`；宝石用颜色 + 符号双编码（红◆ / 蓝● / 绿▲ / 黄★ / 紫■ / 青⬢）；选中格琥珀描边、键盘焦点紫色轮廓、消除格 420ms 缩放闪光。
7. **提示条**：操作方式速查。
8. **遮罩**：暂停（可标注自动暂停原因）、结算（胜利 / 步数用尽 + 得分 + 交换次数 + 连锁 + 最高连锁 + 新纪录）。

## 4. 功能明细

| 模块 | 触发 | 行为 | 边界/异常 |
| --- | --- | --- | --- |
| `Match3Engine.js` 棋盘生成 | 开局 | 逐格随机取色，禁止左侧/上方连续两格同色；生成后校验无初始三消且存在可消交换，最多重试 80 次 | 重试耗尽回退确定性花纹棋盘，后续由自动重排兜底 |
| `Match3Engine.js` 三消扫描 | 每次交换后 | 横向与纵向分别扫描 ≥3 同色连续段，返回组方向、长度与单元格 | 空位（0）不参与匹配 |
| `Match3Engine.js` 交换合法性 | `trySwap(a,b)` | 仅允许上下左右相邻；交换后无三消立刻换回并返回原因 | 同格、非相邻、越界、步数用尽均拒绝 |
| `Match3Engine.js` 消除与下落 | 形成三消 | 清除命中格 → 每列向下压实 → 顶部随机补块，循环直到稳定 | 单次最多 50 轮连锁，防止异常死循环 |
| `Match3Engine.js` 计分 | 每组消除 | 三消 60 / 四消 100 / 五消及以上 160，第 N 轮连锁 ×N | 十字交叉按横纵两组分别计分 |
| `Match3Engine.js` 胜负 | 每次有效交换后 | 分数 ≥ 目标即胜利；步数归零仍未达标判负 | 胜利优先于步数判定；连消中途不结算 |
| `Match3Engine.js` 无解重排 | 稳定后检查 | 不存在任何可三消交换时打乱现有宝石，要求无初始三消且存在可消交换 | 重排次数计入 `reshuffles`，最多 60 次重试后重建棋盘 |
| `Match3Engine.js` 存档恢复 | `restore(save)` | 校验难度、棋盘长度与取值范围、剩余步数、数值字段后恢复对局 | 非法字段返回 false，不改变当前引擎状态 |
| `Match3.jsx` 选块与交换 | 点击宝石 / Enter / 空格 | 第一次点击选中，第二次点相邻格交换；点非相邻格改为选中新格 | 非 playing 状态忽略；交换失败播报原因 |
| `Match3.jsx` 键盘 | 方向键 / Enter / 空格 / Esc | 方向键移动焦点（roving tabindex），Enter/Space 选中或交换，Esc 暂停/继续 | 边界不越界；焦点环与 aria 播报同步 |
| `Match3.jsx` 消除反馈 | 有效交换后 | 对比交换前后棋盘，变化格播放 420ms 缩放闪光；HUD 显示本次得分与连锁段数 | 仅视觉反馈，不阻塞下一次操作 |
| `Match3.jsx` 埋点（约束卡②） | 结算 | 累计 `game-match3-stats-v1`：plays/wins/losses/swaps/matches/cascades/maxCombo/bestScore/timeByLevel | 脏标记 + 1s 防抖 + pagehide 落盘；写入失败静默 |
| `Match3.jsx` 局中存档（约束卡③） | 每次有效交换 / 暂停 / 失焦 | 写 `game-match3-save-v1`：难度、棋盘、分数、剩余步数、已用时长、ts | 序列化 >4096 字符拒写；读取 >24h / 字段非法 / 超长直接清除 |
| `Match3.jsx` 继续对局 | 开始屏点继续 | 读取存档并调用 `restore`，恢复棋盘、分数、步数与计时 | 存档失效时清除并提示「存档已失效」 |
| `Match3.jsx` 存档清理 | 胜利 / 失败 / 重开 | 删除 `game-match3-save-v1`，避免旧局面覆盖新对局 | 删除失败静默忽略 |
| `Match3.jsx` 最佳记录 | 胜利结算 | 按难度写 `game-match3-best-v1`，仅更高分覆盖 | 失败局不计入最佳 |
| `Match3.jsx` 自动暂停 | `visibilitychange(hidden)` + `window blur` | 双路去重，暂停同时落盘存档 | 恢复需手动点「继续」 |
| `Match3.jsx` 番茄钟联动 | 结算且用时 ≥120s | 追加 `pomodoro-sessions-v1`：`{ startTs, endTs, durSec, game:'match3', win, level }` | 不足 120s 不写入；存储异常静默忽略 |
| `DragList.jsx` 联动修正（约束卡①） | 拖拽松手 / Alt+↑↓ | 拖拽项插入到目标位置，其余元素顺移；键盘上移/下移一位 | 首项上移、末项下移无操作；aria-live 播报新位置 |

## 5. 状态说明

- **加载**：路由懒加载期间显示全局「加载中…」；开始屏读取存档与统计为同步 localStorage 操作，无网络请求。
- **成功**：有效交换后棋盘即时更新、闪光与得分提示出现；达到目标分显示胜利遮罩。
- **降级**：localStorage 不可用或配额满时，统计与存档静默降级为内存态，游戏仍可正常游玩。
- **空**：首次进入无存档时显示「暂无存档」；统计全为 0 时显示「累计 0 局」。
- **错误**：非法交换返回原因并保持棋盘不变；棋盘无解自动重排并在计分行提示「已重排」。

## 6. 非功能与约束

- **性能**：8×8 棋盘同步结算，单次交换最多 50 轮连锁；三消扫描 O(rows×cols)；无 Canvas、无动画帧循环，仅 500ms tick 更新时间。
- **移动端**：棋盘 `aspect-ratio: 1/1`，320px 视口单格约 34px；所有按钮 ≥40px、遮罩按钮 ≥44px；最小字号 0.75rem（12px）；宝石颜色均配符号，避免仅靠颜色区分。
- **兼容**：无后端；`min-height: 100vh`；`prefers-reduced-motion` 下关闭闪光与过渡。
- **约束卡①（已知不一致点联动修正）**：基线第 5 节「拖拽为交换语义」修正为插入式排序；改动仅限 `DragList.jsx`、基线 3.1.3 与第 5 节。
- **约束卡②（埋点统计）**：`game-match3-stats-v1` 记录对局、胜负、交换、消除、连锁、最高连锁与分档耗时；脏标记 + 1s 防抖 + `pagehide` 落盘，0~99999 封顶。
- **约束卡③（localStorage 持久化与容量清理）**：`game-match3-save-v1` 单条覆盖写，序列化上限 4096 字符（超限拒写）、24 小时 TTL（读取即清理）、通关/失败/重开即时删除；配额满时放弃存档并静默降级。

## 7. 验收标准

1. **Given** 进入 `/match3`，**When** 页面加载完成，**Then** 显示开始屏、三档难度、未完成对局面板与操作说明，且无 console 错误。
2. **Given** 开局，**When** 点「开始挑战」，**Then** 生成 8×8 棋盘，无初始三消且至少存在一步可消交换，剩余步数与目标分符合所选难度。
3. **Given** 两个相邻宝石交换后形成三连，**When** 完成交换，**Then** 命中的宝石被清除、上方下落补满、得分增加、剩余步数 -1。
4. **Given** 两个相邻宝石交换后无法形成三消，**When** 完成交换，**Then** 两块宝石弹回原位、盘面不变、步数不扣减，并播报「这次交换无法形成三消」。
5. **Given** 一次消除后顶部补充再次形成三消，**When** 结算完成，**Then** 连锁得分按段数倍增，HUD 显示连锁段数。
6. **Given** 分数达到目标，**When** 本次交换结算完成，**Then** 立即显示胜利遮罩，`game-match3-stats-v1` 与 `game-match3-best-v1`（更高分时）写入。
7. **Given** 剩余 1 步且分数未达标，**When** 完成一次有效交换，**Then** 显示步数用尽结算，判负且不计入最佳。
8. **Given** 棋盘不存在任何可消交换，**When** 一次交换结算完成，**Then** 棋盘自动重排为无三消且存在可消交换，并提示「已重排」。
9. **Given** 对局中刷新页面或关闭标签，**When** 24 小时内重新进入，**Then** 显示「继续上次对局」，恢复棋盘、分数、剩余步数与已用时长。
10. **Given** 存档已超过 24 小时或字段非法，**When** 打开开始屏，**Then** 存档被自动清除并显示空态说明，不出现损坏局面。
11. **Given** 对局中切换标签页或窗口失焦，**When** 回到页面，**Then** 已处于暂停态且进度已保存，点「继续」后恢复。
12. **Given** 键盘操作，**When** 用方向键移动焦点并 Enter 选中、移动后再 Enter 交换，**Then** 交换成功且焦点环与 aria-live 播报同步更新；**When** 对局 ≥120s 结束，**Then** `pomodoro-sessions-v1` 追加一条 `game:'match3'` 的记录。

## 8. 存储变更

| 键名 | 用途 | 生命周期 |
| --- | --- | --- |
| `game-match3-stats-v1` | 累计埋点：`{ v:1, plays, wins, losses, swaps, matches, cascades, maxCombo, bestScore, timeByLevel:{easy,normal,hard}, updatedAt }` | 持久（脏标记 + 1s 防抖 + pagehide 落盘） |
| `game-match3-best-v1` | 分档最佳：`{ easy:{score,ts}, normal:{...}, hard:{...} }` | 持久（仅胜利且更高分覆盖，损坏回退空记录） |

| `pomodoro-sessions-v1` | **扩展**：结算 ≥120s 追加 `{ startTs, endTs, durSec, game:'match3', win, level }` | 持久（仅保留最近 14 天） |

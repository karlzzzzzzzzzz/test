# 一笔画（One Stroke）需求文档

> 需求类型：新增功能（新增一个小游戏）· 规模：大型 · 目标路由：`/one-stroke`
> 关联页面：首页作品入口、技术文档中心
> 实现日期：2026-11-18 · 小游戏上线顺序：第 20 款 · 首页作品入口：第 25 张卡

## 1. 需求背景与目标

首页作品入口已有 24 张卡片，解谜类覆盖数独、数织、接水管、迷宫等，但缺少「把整张图的每条线恰好走一次」的欧拉路径玩法。新增第 20 款小游戏**一笔画（One Stroke）**，补齐路径规划类玩法，并复用既有工程约定（引擎与页面壳解耦、六屏状态机、双路自动暂停、键盘可达、番茄钟联动）。

目标：

1. 完整实现一笔画规则：从起点出发、笔不离纸、每条边恰好走一次，走完全部边通关；走进死路可撤销或重置。
2. 提供三档手工关卡（10 / 14 / 25 条边），三档关卡都通过欧拉路径条件校验，保证有解。
3. 在经典关卡之外提供「每日关卡」：按权威日期确定性选择难度与起点，同一天所有人看到同一关卡。
4. 每日关卡面板具备完整的加载 / 成功 / 降级 / 空 / 错误三态，接口失败不影响游戏。
5. 全程可键盘操作与读屏播报，移动端 320px 起不横向溢出。

## 3. 页面结构

1. **顶部栏**：返回首页链接（≥44px 热区）、标题「一笔画 · One Stroke」。
2. **开始屏**：规则说明 → 三档难度选择（轻松 / 标准 / 困难，含边数说明）→「开始画线」→「每日关卡」面板（日期、来源徽标、难度与起点、今日记录、刷新日期、开始每日关卡）→ 累计战绩与当前难度最佳用时 → 操作说明。
3. **游戏主界面 HUD**：计时器、已走边数 / 总边数、卡住标记、难度与模式标签、暂停/继续、撤销、重置、菜单。
4. **棋盘**：正方形画板 + SVG 连线层 + 绝对定位圆点；已走过的边蓝色发光，当前点外圈高亮，可继续画的相邻点绿色描边，起点琥珀色描边；键盘焦点紫色轮廓。
5. **提示条**：操作方式速查。
6. **遮罩**：暂停（可标注自动暂停原因）、通关（用时 + 边数 + 撤销/重置次数 + 新纪录 + 每日记录提示）。

## 4. 功能明细

| 模块 | 触发 | 行为 | 边界/异常 |
| --- | --- | --- | --- |
| `OneStrokeEngine.js` 关卡定义 | 模块加载 | 三档关卡：3×3 日字 10 边、4×4 外环 + 斜线 + 桥 14 边、5×5 双环 + 桥 25 边 | 全部通过 `validateLevel` 欧拉路径校验 |
| `OneStrokeEngine.js` 关卡校验 | 单测 / 调试 | 检查边越界、自环、重复边、连通性、奇数度点数量与起点位置 | 任一不满足返回 `ok:false` 与问题列表 |
| `OneStrokeEngine.js` 开局 | `start(level, opts)` | 按关卡复制边集、重置已走状态、定位起点、计时开始 | 非法难度回退 `easy`；非法起点回退关卡默认起点 |
| `OneStrokeEngine.js` 画线 | `tryMove(node)` | 当前点与目标点之间存在未走边时标记已走、移动当前点、步数 +1 | 同点、无连线、已走过的边分别给出原因 |
| `OneStrokeEngine.js` 通关 | 走完全部边 | 停止计时，状态置 `over`，回调 `onGameOver({result:'win'})` | 通关后不可继续画线或撤销 |
| `OneStrokeEngine.js` 卡住 | 走完一条边后 | 当前点无未走边且仍有剩余边时置 `stuck`，回调 `onStuck` | 不判负，可撤销或重置 |
| `OneStrokeEngine.js` 撤销 | `undo()` | 回退上一条边、当前点回到该边另一端点、步数 -1、撤销次数 +1 | 无历史记录或非 playing 状态返回 false |
| `OneStrokeEngine.js` 重置 | `reset()` | 清空已走边、回到起点、计时归零、重置次数 +1 | 未开局时返回 false |
| `OneStrokeEngine.js` 每日关卡 | `createDailyLevel(date)` | 日期哈希 + mulberry32 选择难度与奇数度起点，同日期结果一致 | 起点必定为奇数度点，保证关卡可解 |
| `OneStroke.jsx` 选点与画线 | 点击圆点 / Enter / 空格 | 相邻未走边直接画出；非法目标不改变盘面并播报原因 | 非 playing 状态忽略 |
| `OneStroke.jsx` 键盘 | 方向键 / Enter / 空格 / Z / Esc | 方向键在网格上移动焦点（只落到存在的点），Enter/Space 画线，Z/Backspace 撤销，Esc 暂停/继续 | 边界不越界；焦点环与 roving tabindex 同步 |
| `OneStroke.jsx` 每日日期（约束卡①） | 进入页面 / 点刷新 | 请求 `timeapi.io` 的 `Asia/Shanghai` 当前时间（AbortController 6s 超时） | 超时、HTTP 错误、返回格式异常均降级本地日期 |
| `OneStroke.jsx` 三态面板（约束卡②） | 日期请求生命周期 | 请求中显示「正在同步…」加载态；成功显示关卡预览；失败显示降级说明；日期无法解析时显示空态与重试 | 30s 内重复刷新只提示不请求；请求进行中去重 |
| `OneStroke.jsx` 自动暂停 | `visibilitychange(hidden)` + `window blur` | 双路去重，仅在 playing 时暂停一次 | 恢复需手动点「继续」 |
| `OneStroke.jsx` 埋点 | 通关结算 | 写 `game-onestroke-stats-v1`：plays/wins/undos/resets/timeByLevel | 存储不可用时仅内存累计，不阻塞结算 |
| `OneStroke.jsx` 最佳记录 | 通关结算 | 按难度写 `game-onestroke-best-v1`，仅更短用时覆盖 | 字段损坏时读取回退空记录 |
| `OneStroke.jsx` 每日记录 | 每日关卡通关 | 写 `game-onestroke-daily-v1` 按日期记录 time/level/ts | 只保留合法日期与合法数值 |
| `OneStroke.jsx` 番茄钟联动 | 通关且用时 ≥120s | 追加 `pomodoro-sessions-v1`：`{ startTs, endTs, durSec, game:'one-stroke', win, level }` | 不足 120s 不写入；存储异常静默忽略 |
| `DragList.jsx` 联动修正（约束卡③） | 拖拽松手 / Alt+↑↓ | 拖拽项插入到目标位置，其余元素顺移；键盘上移/下移一位 | 首项上移、末项下移无操作；aria-live 播报新位置 |

## 5. 状态说明

- **加载**：路由懒加载期间显示全局「加载中…」；每日面板请求期间显示「同步中」徽标与加载文案，刷新按钮禁用，但经典关卡可正常开始。
- **成功**：每日日期来源为网络时显示绿色「网络日期」徽标；通关后显示结算卡与「新纪录！」提示（若刷新最佳）。
- **降级**：时间接口超时或不可用时回退本地日期，显示琥珀色「本地日期」徽标与降级说明，每日关卡仍可开始。
- **空**：尚无战绩时开始屏显示「累计 0 局」；日期无法生成关卡时显示「暂无可用的每日关卡，请刷新重试」。
- **错误**：所有 localStorage 读写用 try/catch 包裹，失败静默降级为内存态；非法画线由引擎返回原因并通过 aria-live 播报。

## 6. 非功能与约束

- **性能**：单局最多 25 条边、25 个点，纯 DOM + SVG，无 Canvas；每次画线只重渲染一次快照，500ms tick 仅更新时间。
- **移动端**：棋盘 `aspect-ratio: 1/1`，320px 视口下 5×5 关卡单点间距约 60px，圆点 40px；所有按钮 ≥40px、遮罩按钮 ≥44px；最小字号 0.75rem（12px）。
- **兼容**：无后端；`min-height: 100vh`；`prefers-reduced-motion` 下关闭圆点/按钮过渡。
- **约束卡①（外部 API + 失败降级）**：每日关卡日期优先取 `https://timeapi.io/api/Time/current/zone?timeZone=Asia%2FShanghai` 的 `dateTime`（6s 超时 + AbortController），失败降级本地日期；降级不影响关卡可玩性。
- **约束卡②（加载 / 空 / 错误三态）**：每日面板显式建模 `loading / ready / error / empty` 四态；请求进行中模块级去重，刷新 30s 节流；错误态保留重试入口。
- **约束卡③（已知不一致点联动修正）**：基线第 5 节「拖拽为交换语义」修正为插入式排序；改动仅限 `DragList.jsx`、基线 3.1.3 与第 5 节，首页其他交互不变。

## 7. 验收标准

1. **Given** 进入 `/one-stroke`，**When** 页面加载完成，**Then** 显示开始屏、三档难度与每日关卡面板，且无 console 错误。
2. **Given** 轻松关开局，**When** 点「开始画线」，**Then** 棋盘出现 10 条灰线和起点高亮，当前点为起点。
3. **Given** 当前点与相邻点之间存在未走边，**When** 点击相邻点，**Then** 该边变为蓝色、当前点移动、已走边数 +1。
4. **Given** 一条边已经走过，**When** 再次尝试沿该边返回，**Then** 走子被拒绝并播报「这条边已经走过」。
5. **Given** 当前点与目标点之间没有连线，**When** 点击目标点，**Then** 盘面不变并播报「两点之间没有连线」。
6. **Given** 已走若干条边，**When** 点击「撤销」，**Then** 最后一条边恢复未走、当前点回到该边另一端点、步数与撤销次数同步更新。
7. **Given** 已走若干条边，**When** 点击「重置」，**Then** 全部边恢复未走、当前点回到起点、计时归零。
8. **Given** 走成死路（当前点无未走边但仍有剩余边），**When** 画完最后一条可走边，**Then** 显示「无路可走」标记与 aria 播报，仍可撤销或重置。
9. **Given** 按欧拉路径走完全部边，**When** 最后一条边落下，**Then** 显示通关遮罩、计时停止、`game-onestroke-stats-v1` 与最佳记录写入。
10. **Given** 每日关卡，**When** 同一天两次生成，**Then** 难度与起点完全一致；**When** 时间接口不可用，**Then** 自动降级本地日期并显示降级说明，仍可开局。
11. **Given** 每日面板连点刷新，**When** 距上次请求不足 30 秒，**Then** 不发起新请求并提示「刷新过于频繁」。
12. **Given** 键盘操作，**When** 用方向键移动焦点并 Enter 画线、Z 撤销、Esc 暂停，**Then** 操作成功且焦点环与 aria-live 播报同步更新；**When** 通关且总时长 ≥120s，**Then** `pomodoro-sessions-v1` 追加一条 `game:'one-stroke'` 的记录。

## 8. 存储变更

| 键名 | 用途 | 生命周期 |
| --- | --- | --- |
| `game-onestroke-stats-v1` | 累计埋点：`{ plays, wins, undos, resets, timeByLevel:{easy,normal,hard}, updatedAt }` | 持久（每次通关写入，读取逐字段归一，失败静默） |
| `game-onestroke-best-v1` | 分档最佳：`{ easy:{time,moves,ts}, normal:{...}, hard:{...} }` | 持久（仅更短用时覆盖，损坏回退空记录） |
| `game-onestroke-daily-v1` | 每日关卡记录：`{ 'YYYY-MM-DD': { time, level, ts } }` | 持久（按日期覆盖当天记录） |
| `pomodoro-sessions-v1` | **扩展**：通关 ≥120s 追加 `{ startTs, endTs, durSec, game:'one-stroke', win, level }` | 持久（仅保留最近 14 天） |

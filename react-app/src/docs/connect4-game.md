# 四连棋（Connect Four）需求文档

> 生成于 2026-11-03，规模：大型，类型：数据与埋点 + AI 对手。本文同时作为项目第 13 款小游戏（`/connect4`）的实现说明文档。

## 1. 背景与目标

本站已有 12 款小游戏（飞机大战、2048、俄罗斯方块、贪吃蛇、打砖块、记忆翻牌、打地鼠、数字华容道、关灯挑战等），缺少一款「回合制、纯点按、与电脑对弈」的策略类游戏。四连棋把规则压缩成一句话（点一列落子，先连成四子获胜），单局通常 15~30 手、1~3 分钟，适合手机单手竖屏操作，且与现有所有游戏的玩法机制不重复。

**目标（可衡量）**：
- 新增 `/connect4` 路由，首屏可交互，分包体积 < 15 kB（gzip）。
- 320 / 360 / 375 / 414 / 480 / 600 / 768 / 820 / 1024 九档宽度横向溢出为 0，棋盘格热区 ≥ 40×40，可见字号 ≥ 12px。
- 首页作品卡片数由 12 增至 13，统计条「功能模块」同步显示 13。
- 玩法逻辑（落子重力、四方向成四、回合流转、三档 AI、计分、暂停、超时）单测覆盖。

```

├── .c4-hud                步数 · 难度 · 倒计时（剩余秒数）
├── .c4-turn               轮到你落子 / 电脑思考中 / 已暂停 / 本局结束
├── .c4-live-region        aria-live polite（视觉隐藏，仅播报）
├── .c4-board-wrap
│   └── .c4-board[role=grid]   7 行 × 6 列 .c4-cell-wrap > button.c4-cell > .c4-disc
├── .c4-actions            重新开局 · 返回首页
├── .c4-overlay（start）    难度选择：轻松 / 挑战 / 专家
├── .c4-overlay（paused）   手动/自动暂停说明 + 继续 / 返回
```

## 4. 功能点明细

| 模块 | 交互 | 规则/逻辑 | 异常处理 |
| --- | --- | --- | --- |
| 路由接入 | 访问 `#/connect4` | `App.jsx` 增加 `lazy(() => import('./pages/Connect4'))` + `Suspense` | 加载失败由 404 路由兜底，不新增错误边界 |
| 棋盘规格 | 静态 6 列 × 7 行 | 常量 `CONNECT4.COLS/ROWS`；6 列保证 320px 下每格 ≥40px | 不做响应式改列，避免同一局棋盘尺寸变化 |
| 难度选择 | 点按「轻松 / 挑战 / 专家」 | easy 基准 600 分、AI 40% 随机走子；normal 900 分、1 层局面评估；hard 1200 分、alpha-beta 深度 4 | 遮罩期棋盘 `pointer-events:none`，防止误触 |
| 落子重力 | 点按任意格（按钮） | 棋子落到该列最低空格；列满则忽略 | 非法列、非整数、满列一律返回 false，不增加步数 |
| 回合流转 | 玩家先手 | 玩家落子 → `turn='ai'`；页面延迟 420ms 调 `aiTurn()` → `turn='player'` | 暂停/结算期间 `aiTurn()` 被忽略；恢复后由页面重新调度 |
| 成四判定 | 每次落子后检查 | 以最后落子为中心，检查横/竖/两条斜线连续同色 ≥4，返回获胜索引 | 同时出现多条四连只取第一条，索引排序后高亮 |
| 玩家胜利 | 落子后成四 | `state='over'`、`result='win'`、回调计分 | 结算后棋盘禁用，重复点按无效 |
| 电脑胜利 | AI 落子后成四 | `state='over'`、`result='lose'`，本局 0 分 | 不写入最佳记录 |
| 平局 | 棋盘 42 格填满仍无四连 | `state='over'`、`result='draw'`，0 分 | 落子或 AI 调用时判定，不依赖外部轮询 |
| 倒计时 | HUD 每 250ms 刷新 | 首次玩家落子启动；剩余 = 180 − 已用，`ceil` 显示 | 剩余 ≤ 0 → `result='timeout'`，0 分，不写最佳 |
| 计分 | 胜利时结算 | `score = max(100, round(base − 落子数×12 − 用时秒×2))` | 向下取整、封底 100，不会为负 |
| 三档 AI | 电脑回合自动落子 | 轻松：能赢必赢，40% 随机，70% 概率堵三连；挑战：能赢/必堵 + 1 层局面评估；专家：alpha-beta 深度 4 | AI 计算同步执行（6×7、深度 4 节点量小），不阻塞可感知交互 |
| 暂停/恢复 | 顶部按钮；切后台/失焦自动暂停 | `visibilitychange` + `window.blur` 双触发去重；暂停冻结计时并清理 AI 延迟定时器 | 恢复需手动点「继续」，恢复后若轮到电脑会重新调度落子 |
| 重新开局 | 底部「重新开局」 | 以当前难度清空棋盘、回合、步数与计时 | 暂停时按钮禁用；结算后可用「再来一局」 |
| 键盘无障碍 | 方向键 / Home / End / Enter / Space | 棋盘 `role=grid`，行 `role=row`，格 `role=gridcell` + 原生 `button`；roving tabindex；方向键移动焦点，Enter/Space 由按钮原生点击落子 | 电脑回合使用 `aria-disabled` 而非 `disabled`，保留键盘焦点 |
| 读屏播报 | `aria-live="polite"` | 播报「游戏开始」「你落在第 N 列」「电脑落在第 N 列」「四连成功」「时间到」 | 以 `lastAction + moves + turn` 去重，tick 刷新不重复播报 |
| 成绩存储 | 胜利后写最佳记录 | 键 `game-connect4-best-v1`，按难度存 `{score, moves, time}`，仅当分数更高时覆盖 | localStorage 不可用/配额满 → 仅内存展示，结算屏提示「本局成绩未保存」 |
| 行为埋点 | 开局 / 胜 / 负 / 平 / 超时 | 键 `game-connect4-stats-v1`：`plays`、`wins`、`losses`、`draws`、`moves`、`timeByLevel`；脏标记 + 1s 兜底 + `pagehide` 落盘 | JSON 损坏回退空结构；写入失败静默跳过，不阻断游戏 |
| 首页入口 | 卡片「开始挑战 →」 | `ENTRIES` 新增一项（`to:'/connect4'`、`span:'3'`），复用 `CardLayout`；沿用 `home-entry-clicks` 计数 | 卡片字段缺失时沿用 CardLayout 既有降级 |
| 首页统计条 | 进入视口时数字滚动 | 「功能模块」由 12 改为 13 | 值为 0 或 reduced-motion 时直接显示终值（沿用 `AnimatedNumber`） |
| PRD 入库 | 访问 `#/docs/connect4-game` | 本文件放入 `src/docs/`，在 `registry.js` 登记 slug/title/summary/date/tags/readTime | 未登记时 `/docs` 列表不显示，详情页 404（既有行为） |
| 移动端适配 | 320~1024 各档 | 断点沿用项目三级体系：≥1024 / 768~1023 / <768 / <480 | 见第 6 节约束卡与验收标准 |

## 5. 状态说明

页面状态机：`start → playing ⇄ paused → over`；`over` 内用 `result` 区分 `win | lose | draw | timeout`。

**三态**：
- **加载**：懒加载分包未就绪时显示 `.game-loading`「加载中…」（全局 `Suspense` 兜底）。
- **空**：尚无历史最佳时，开始遮罩与结算屏显示「暂无记录 / —」。
- **错误**：localStorage 不可用时，最佳记录与埋点降级为内存态，结算屏追加「本局成绩未保存（本地存储不可用）」，游戏流程不中断。

**边界情况（≥4）**：
1. 320px 宽度：6 列 × 5px 间距 + 10px 内边距下格子约 41.8px，满足 ≥40px；若未来改成 7 列会跌破阈值，需重新评估。
2. 暂停与 AI 延迟竞态：AI 定时器在暂停时被清理；恢复后若 `turn==='ai'` 重新调度，不会出现「暂停中电脑偷偷落子」。
3. 玩家落子成四与超时同帧：`_finish` 幂等由 `state` 拦截，先进入 over 的判定生效，不重复回调。
4. 电脑填满最后一列：`aiTurn()` 找不到合法列时按平局收尾，不抛异常。
5. 连点同一列：每次点按都触发一次合法落子，第二次时已轮到电脑则被忽略（`turn` 守卫）。
6. 切后台超过 180 秒：恢复后首次 tick 直接进入 `timeout`，剩余时间显示 00:00，不出现负值。

## 6. 非功能需求

### 6.1 移动端（约束卡 ②·必须兼容移动端）

- 棋盘 `width:100%; max-width:420px; box-sizing:border-box`，**禁止**使用 `vw` 宽度（历史审计中曾因 `vw` 与 `min-content` 互相推高造成横向溢出）。
- 格子 `min-width:40px; min-height:40px`，行轨道 `repeat(6, minmax(0,1fr))`，避免 6 列在 320px 下被内容撑破。
- `.c4-page` 使用 `min-height:100svh`（iOS Safari 工具栏可见时 `100vh` 会超出可视区）。
- <768 断点：页面 padding 16/14/48，棋盘 max-width 380；<480：padding 14/12/32，棋盘 max-width 340，gap 8 → 5。
- 动作区按钮 <480 时纵向堆叠；所有按钮/链接最小高度 40px（主操作 44px）。
- 触控：棋盘 `touch-action:manipulation`、`user-select:none`，关闭 iOS 双击缩放与长按菜单。

### 6.2 无障碍（约束卡 ③·键盘可访问性与 aria）

- 棋盘 `role="grid"` + `role="row"` + `role="gridcell"`，格子内为原生 `button`。
- roving tabindex：方向键按行列移动（不跨列环绕）、Home/End 到行首/行尾、Enter/Space 触发落子。
- 焦点环统一 `outline:2px solid #aa3bff; outline-offset:2px`；电脑回合用 `aria-disabled` 保留焦点。
- `aria-live="polite"` 播报落子列、回合切换与胜负；计时器 `aria-live="off"`。
- `prefers-reduced-motion:reduce` 时删除落子下落动画，保留棋子颜色区分（不只靠动画表达状态）。

### 6.3 数据语义（约束卡 ①·与基线不一致点联动修正）

- 新页面只允许出现「本局」「历史最佳」两种口径，分别对应内存快照与 `game-connect4-best-v1` 持久记录，不出现按天/按周聚合文案。
- 埋点键 `game-connect4-stats-v1` 的 `plays/wins/losses/draws` 明确为**全生命周期累计值**，文案统一为「累计」；如需按天统计另开键（本需求不做）。

### 6.4 性能与安全

- 引擎纯逻辑、无 DOM 依赖；落子 O(1)，成四判定 O(1)（沿四方向最多各 3 格），AI 深度 4 的搜索规模在 6×7 棋盘上为毫秒级。
- 页面按需懒加载，独立分包；不引入新依赖（不新增 npm 包）。
- AI 只在缓存局面上运算，不读取任何网络/外部数据；随机源可注入，便于单测。

## 7. 验收标准

1. **Given** 首页已渲染，**When** 查看作品入口区，**Then** 出现第 13 张「四连棋」卡片且链接指向 `/connect4`。（主干）
2. **Given** 首页统计条进入视口，**When** 数字滚动结束，**Then** 「功能模块」显示 13，且与入口卡数量一致。（主干）
3. **Given** 打开 `#/connect4`，**When** 选择「轻松」，**Then** 棋盘为 6 列 × 7 行且状态进入 playing，玩家先手。（主干）
4. **Given** 空棋盘点按第 1 列任意格，**When** 检查棋盘，**Then** 棋子落在第 1 列最底行，步数 +1，随后轮到电脑。（主干）
5. **Given** 同一列已落满 7 子，**When** 再次点按该列，**Then** 落子被忽略且步数不变。（异常）
6. **Given** 玩家在某行已有 3 连，**When** 点按补成第 4 子的列，**Then** 立即进入结算遮罩，标题为「四连成功」，获胜四格高亮。（主干）
7. **Given** 电脑存在一步成四的落点，**When** 轮到电脑，**Then** 电脑选择该列并结束本局，结果为 lose。（主干）
8. **Given** 玩家有 3 连且电脑无直接胜点，**When** 轮到挑战难度电脑，**Then** 电脑落子封堵该列而不是随机走子。（主干）
9. **Given** 游戏进行中切到后台 10 秒，**When** 回到前台，**Then** 计时冻结在切走时的值，需手动点「继续」才恢复；电脑不会在暂停期间落子。（异常）
10. **Given** 倒计时归零，**When** 触发一次 tick，**Then** 进入「时间到」结算，剩余显示 00:00 而非负数，且不写最佳记录。（异常）
11. **Given** localStorage 被禁用，**When** 完成一局并查看结算屏，**Then** 游戏正常结算并提示「本局成绩未保存」，不抛异常。（异常）
12. **Given** 视口宽 320px 与 375px，**When** 检查页面，**Then** `documentElement.scrollWidth − clientWidth = 0`，无元素越界，所有可见按钮热区 ≥40×40，可见文字字号 ≥12px。（主干 + 约束卡②）
13. **Given** 仅使用键盘，**When** 用方向键移动到目标格并按 Enter，**Then** 棋子落在该列，且 `aria-live` 播报落子列；电脑回合焦点不丢失。（主干 + 约束卡③）

## 8. 存储变更

| 键名 | 用途 | 生命周期 |
| --- | --- | --- |
| `game-connect4-best-v1` | 各难度历史最佳 `{easy:{score,moves,time}, normal:{...}, hard:{...}}`，仅胜利且分数更高时覆盖 | 持久 |
| `game-connect4-stats-v1` | 行为埋点：`{plays, wins, losses, draws, moves, timeByLevel, updatedAt}`，全生命周期累计 | 持久（脏标记 + 1s 兜底 + pagehide 落盘） |

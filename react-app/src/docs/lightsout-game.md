# 关灯挑战（Lights Out）需求文档

> 生成于 2026-11-02，规模：大型，类型：数据与埋点。本文同时作为项目第 8 款小游戏（`/lightsout`）的实现说明文档。

## 1. 背景与目标

本站已上线 8 款游戏（飞机大战、2048、俄罗斯方块、贪吃蛇、打砖块、记忆翻牌、打地鼠、数字华容道），但缺少一款「单指点按即可完成、无需移动视线追踪」的纯逻辑解谜。关灯挑战用一句话规则（点一格翻转它和上下左右）覆盖「思考 + 触控」，单局 1~3 分钟，适合手机单手场景。

**目标（可衡量）**：
- 新增 `/lightsout` 路由，首屏可交互，分包体积 < 15 kB（gzip）。
- 320 / 360 / 375 / 414 / 480 / 600 / 768 / 820 / 1024 九档宽度横向溢出为 0，格子热区 ≥ 40×40，可见字号 ≥ 12px。
- 首页作品卡片数由 11 增至 12，统计条「功能模块」同步显示 12。
- 玩法逻辑（翻转、胜利判定、计分、撤销、暂停）单测覆盖率 100%（分支均有用例）。

## 3. 页面结构

```
.lo-page
├── header.lo-top          返回首页 · 标题「关灯挑战」· 暂停/继续
├── .lo-hud                步数 · 剩余灯 · 倒计时（剩余秒数）
├── .lo-live-region        aria-live polite（视觉隐藏，仅播报）
├── .lo-board-wrap
│   └── .lo-board[role=grid]   rows × cols 个 .lo-cell > button.lo-tile
├── .lo-actions            撤销(N) · 重新打乱 · 返回首页
├── .lo-overlay（start）    难度选择：轻松 4×4 / 挑战 5×5 / 专家 6×6
├── .lo-overlay（paused）   手动/自动暂停说明 + 继续 / 返回
├── .lo-overlay（over）     胜利结算：步数/用时/得分/历史最佳 + 再来一局
└── .lo-overlay（timeout）  超时失败：已完成格数/步数 + 重开 / 返回
```

新增区块：整个 `.lo-page`（新路由），首页仅新增一张卡片，统计条只改一处数字。

## 4. 功能点明细

| 模块 | 交互 | 规则/逻辑 | 异常处理 |
| --- | --- | --- | --- |
| 路由接入 | 访问 `#/lightsout` | `App.jsx` 增加 `lazy(() => import('./pages/LightsOut'))` + `Suspense` | 加载失败由 404 路由兜底，不新增错误边界 |
| 难度选择 | 点按「轻松 4×4 / 挑战 5×5 / 专家 6×6」 | `DIFFICULTY`：easy 4×4、打乱 5 步、限时 90s、基准分 600；normal 5×5、8 步、150s、900；hard 6×6、12 步、180s、1200 | 遮罩期棋盘 `pointer-events:none`，防止误触 |
| 开局生成 | 点难度即开局 | 从「全灭」状态随机施加 `scramble` 次合法翻转（同一格不连续两次），因此**必然可解**；若结果全灭则重抽 | 循环重抽上限 20 次，超限退化为全亮（仍可解） |
| 翻转规则 | 点按任一格（按钮） | 翻转自身 + 上下左右邻居（越界忽略），`steps += 1` | 非 playing 态、暂停态、结算态一律忽略，不计数 |
| 胜利判定 | 每次翻转后检查 | 剩余亮灯数 = 0 → `state='over'`，计算得分并回调 | 同一次翻转同时灭掉最后多盏灯按胜利处理，不重复结算 |
| 计分 | 胜利时结算 | `score = max(100, round(base − max(0, steps − par) × 8 − elapsedSec × 2))`，`par = scramble` 步 | 分数向下取整并封底 100，不会为负 |
| 倒计时 | HUD 每 200ms 刷新 | 首次翻转启动；剩余 = 限时 − 已用，`ceil` 显示 | 剩余 ≤ 0 → `state='failed'`，展示超时遮罩，不写入最佳记录 |
| 暂停/恢复 | 顶部按钮；切后台/失焦自动暂停 | `visibilitychange` + `window.blur` 双触发去重；暂停冻结计时并禁用棋盘 | 恢复需手动点「继续」，不自动续跑 |
| 撤销 | 底部「撤销 (N)」，每局 3 次 | 逆向翻转最后一步、回退历史指针；**步数不返还**（失误仍计分） | 无可撤销步骤或次数用尽时按钮禁用，不报错 |
| 重新打乱 | 底部「重新打乱」 | 以当前难度重开一局，步数与用时归零 | 结算态点按等同再来一局；不累计埋点 play 计数以外的副作用 |
| 键盘无障碍 | 方向键 / Enter / Space / Home / End | 棋盘 `role=grid`，行 `role=row`，格 `role=gridcell` + `button`；roving tabindex（仅焦点格 `tabIndex=0`） | 焦点格被翻转后不跳格；`prefers-reduced-motion` 关闭动画 |
| 读屏播报 | `aria-live="polite"` | 播报「剩余 N 盏」「已撤销」「全部熄灭」；倒计时 `aria-live="off"` | 连点合并为最后一次文案，不排队堆积 |
| 成绩存储 | 胜利后写最佳记录 | 键 `game-lightsout-best-v1`，按难度存 `{score, steps, time}`，仅当分数更高时覆盖 | localStorage 不可用/配额满 → 仅内存展示，结算屏提示「本局成绩未保存」 |
| 行为埋点 | 开局 / 胜利 / 超时 | 键 `game-lightsout-stats-v1`：`plays`、`wins`、`steps`、`timeByLevel`；脏标记 + 1s 兜底 + `pagehide` 落盘 | JSON 损坏回退空结构；写入失败静默跳过，不阻断游戏 |
| 首页入口 | 卡片「开始挑战 →」 | `ENTRIES` 新增一项（`to:'/lightsout'`、`span:'3'`），复用 `CardLayout`；沿用 `home-entry-clicks` 计数 | 卡片字段缺失时沿用 CardLayout 既有降级（无 footer 则显示「查看详情 →」） |
| 首页统计条 | 进入视口时数字滚动 | 「功能模块」由 11 改为 12 | 值为 0 或 reduced-motion 时直接显示终值（沿用现有 `AnimatedNumber`） |
| PRD 入库 | 访问 `#/docs/lightsout-game` | 本文件放入 `src/docs/`，在 `registry.js` 登记 slug/title/summary/date/tags/readTime | 未登记时 `/docs` 列表不显示，详情页 404（既有行为） |
| 移动端适配 | 320~1024 各档 | 断点沿用项目三级体系：≥1024 / 768~1023 / <768 / <480 | 见第 6 节约束卡与验收标准 |

## 5. 状态说明

页面状态机：`start → playing ⇄ paused → over | failed`（`over`/`failed` 可经「再来一局/重开」回到 `playing`）。

**三态**：
- **加载**：懒加载分包未就绪时显示 `.game-loading`「加载中…」（全局 `Suspense` 兜底）。
- **空**：尚无历史最佳时，结算屏「历史最佳」显示「暂无记录」；`/docs` 列表在本文件未登记时不出现该条目（既有空态）。
- **错误**：localStorage 不可用时，最佳记录与埋点降级为内存态，结算屏追加一行「本局成绩未保存（本地存储不可用）」，游戏流程不中断。

**边界情况（≥4）**：
1. 320px 宽度 + 专家 6×6：格子 40.67px，恰好满足 ≥40px 热区；若未来增大到 7 列将跌破阈值，需重新评估。
2. 倒计时与暂停竞态：同一帧内先触发 `pause()` 再 `tick()`，以 `state==='playing'` 为准，不再结算超时。
3. 撤销与胜利竞态：最后一步熄灭全部灯后立即点撤销——因已进入 `over`，撤销按钮禁用，不产生「胜利后回退」的负分。
4. 快速连点同一格：每次点按都是合法翻转，步数照常累加（这是玩法的一部分，不做节流）。
5. 切后台超过限时时长：恢复时若已超时，直接进 `failed` 遮罩，不出现「剩余 -3s」负值。

## 6. 非功能需求

### 6.1 移动端（约束卡 ②·必须兼容移动端）

- 棋盘 `width:100%; max-width:420px; box-sizing:border-box`，**禁止**使用 `vw` 宽度（`vw` 会与页面 `min-content` 互相推高，历史审计中曾导致 5~14px 溢出）。
- 格子 `min-height:40px`，`.lo-cell` 使用 `minmax(0,1fr)` 轨道，避免 6 列在 320px 下被内容撑破。
- `.lo-page` 使用 `min-height:100svh`（iOS Safari 工具栏可见时 `100vh` 会超出可视区）。
- <768 断点：页面 padding 16/14/48，棋盘 max-width 380；<480：padding 14/12/32，棋盘 max-width 340，gap 由 8 降为 6。动作区按钮 <480 时纵向堆叠，最小高度 40px。
- 触控：棋盘 `touch-action:manipulation`、`user-select:none`，关闭 iOS 双击缩放与长按菜单。

### 6.2 无障碍（约束卡 ③·键盘可访问性与 aria）

- 棋盘 `role="grid"` + `role="row"` + `role="gridcell"`，格子内为原生 `button`。
- roving tabindex：方向键按行列移动（不跨行环绕）、Home/End 到行首/行尾、Enter/Space 触发翻转。
- 焦点环统一 `outline:2px solid #aa3bff; outline-offset:2px`；`aria-pressed` 反映灯态。
- `aria-live="polite"` 播报剩余灯数与撤销结果；计时器 `aria-live="off"`。
- `prefers-reduced-motion:reduce` 时删除入场/翻转过渡动画，保留颜色区分（不只靠动画表达状态）。

### 6.3 数据语义（约束卡 ①·与基线不一致点联动修正）

- 基线已知不一致点 #1 为「番茄钟『今日』文案但计数是累计值」。本需求**不修改番茄钟**，而是把该问题作为「同类缺陷自查项」：新页面只允许出现「本局」「历史最佳」两种口径，且二者分别对应「内存局内快照」与 `game-lightsout-best-v1` 持久记录，不出现按天/按周聚合文案。
- 埋点键 `game-lightsout-stats-v1` 的 `plays/wins` 明确为**全生命周期累计值**，文案统一为「累计」；如需按天统计另开键（本需求不做）。

### 6.4 性能与埋点

- 引擎纯逻辑、无 DOM 依赖；单次翻转复杂度 O(1)，倒计时刷新间隔 200ms。
- 页面按需懒加载，独立分包；不引入新依赖（不新增 npm 包）。
- 首页点击计数沿用 `home-entry-clicks` 既有脏标记延迟写入，并带 0~99999 封顶。

## 7. 验收标准

1. **Given** 首页已渲染，**When** 查看作品入口区，**Then** 出现第 12 张「关灯挑战」卡片且链接指向 `/lightsout`。（主干）
2. **Given** 首页统计条进入视口，**When** 数字滚动结束，**Then** 「功能模块」显示 12，且与入口卡数量一致。（主干）
3. **Given** 打开 `#/lightsout`，**When** 选择「轻松 4×4」，**Then** 棋盘为 4×4 且至少 1 盏灯亮起，状态进入 playing。（主干）
4. **Given** 棋盘中央格被点按，**When** 检查上下左右四格与自身，**Then** 这 5 格灯态全部反转，步数 +1。（主干）
5. **Given** 棋盘角格被点按，**When** 检查越界邻居，**Then** 只翻转 3 格（自身 + 2 个界内邻居），不报错。（异常）
6. **Given** 已按「打乱记录」逆序点完所有翻转，**When** 最后一盏灯熄灭，**Then** 立即进入胜利遮罩，得分 = `max(100, base − 超出行数惩罚 − 用时惩罚)`。（主干）
7. **Given** 本局已撤销 3 次，**When** 再次点按「撤销」，**Then** 按钮为禁用态且棋盘不变。（异常）
8. **Given** 游戏进行中切到后台 10 秒，**When** 回到前台，**Then** 计时冻结在切走时的值，需手动点「继续」才恢复。（异常）
9. **Given** 倒计时归零，**When** 触发一次 `tick`，**Then** 进入超时失败遮罩，剩余时间显示 00:00 而非负数，且不写入最佳记录。（异常）
10. **Given** localStorage 被禁用，**When** 完成一局并查看结算屏，**Then** 游戏正常结算并提示「本局成绩未保存」，不抛异常。（异常）
11. **Given** 视口宽 320px 与 375px，**When** 逐页检查，**Then** `documentElement.scrollWidth − clientWidth = 0`，无元素越界，所有可见按钮热区 ≥40×40，可见文字字号 ≥12px。（主干 + 约束卡②）
12. **Given** 仅使用键盘，**When** 用方向键移动到目标格并按 Enter，**Then** 该格被翻转，且 `aria-live` 播报剩余灯数。（主干 + 约束卡③）
13. **Given** 系统开启「减少动画」，**When** 打开页面并翻转格子，**Then** 无过渡/弹跳动画，但亮/灭颜色仍可区分。（主干）

## 8. 存储变更

| 键名 | 用途 | 生命周期 |
| --- | --- | --- |
| `game-lightsout-best-v1` | 各难度历史最佳 `{easy:{score,steps,time}, normal:{...}, hard:{...}}`，仅胜利且分数更高时覆盖 | 持久 |
| `game-lightsout-stats-v1` | 行为埋点：`{plays, wins, steps, timeByLevel, updatedAt}`，全生命周期累计 | 持久（脏标记 + 1s 兜底 + pagehide 落盘） |

复用既有键：`home-entry-clicks`（首页卡片点击计数，`Home.jsx` 既有逻辑）。局中状态**不持久化**（刷新即重开），与记忆翻牌一致的取舍。

# 数独 新增小游戏 需求文档

> 随机生成于 2026-11-10，规模：大型，类型：新增功能

## 1. 背景与目标

现有 14 款小游戏覆盖动作、消除、棋类、寻路，但缺少「数字逻辑推理」类玩法。数独用 9×9 填数把「排除法推理 + 候选数管理」压缩成一局 2~5 分钟的挑战，目标：每局题目**保证唯一解**、触控与键盘双通道等价、错误三次判负形成紧凑节奏，读屏用户可完整游玩。

## 3. 页面结构

1. **顶部栏**：返回首页链接（≥40px 高）、标题「数独」、暂停/继续按钮（仅游戏中显示）。
2. **HUD**（四格）：已填格数、错误 x/3、提示剩余、倒计时（`role=timer`，不逐秒播报）。
3. **盘面**（新）：`role=grid` → 9 行 `role=row` → 81 格 `role=gridcell`；3×3 宫之间加粗分隔线；已知格深色底、玩家填入格浅色、选中格高亮、同行/列/宫淡色联动、相同数字格描边高亮、错误格红标。
4. **数字面板**（新）：1~9 + 擦除共 10 个按钮，单键热区 ≥40px，是全部写入动作的唯一入口。
5. **动作区**（新）：笔记模式开关（aria-pressed）、提示（含剩余次数）、撤销；暂停时整体禁用。
6. **遮罩**：start / loading / error / paused / over 五种，全屏 `position: fixed` 卡片居中可滚动；paused 遮罩**完全遮蔽盘面数字**（防暂停抄题）。
7. **结算屏**（over）：胜/负标题、得分明细（基准分/时间扣/错误扣/提示扣）、通关寄语区、再来一局/返回首页。

## 4. 功能点明细

| 模块 | 交互 | 规则/逻辑 | 异常处理 |
| --- | --- | --- | --- |
| `src/game/SudokuEngine.js` 终盘生成 | 选档后自动触发 | 回溯法填满 81 格，行/列/宫均含 1~9 不重复；随机源注入保证可测 | 生成异常抛错进入 error 屏 |
| `src/game/SudokuEngine.js` 挖空 | 终盘生成后执行 | 按中心对称成对挖空；每挖一对用解计数器（计到 2 即停）复核唯一解，不唯一则回退该对；单盘尝试上限 200 次 | 尝试耗尽重新生成终盘，至多 3 次，仍失败抛错 |
| `src/game/SudokuEngine.js` 三档难度 | 开始页选择 | 轻松 挖 36 空（已知 45）/ 限时 300s / 基准 600；挑战 挖 46 空（已知 35）/ 480s / 900；专家 挖 52 空（已知 29）/ 600s / 1200 | 非法档位回退 easy |
| `src/pages/Sudoku.jsx` 格子选中 | 点按格子 / 方向键 | 选中格高亮并联动行列宫；roving tabindex 焦点跟随 | 非 playing 状态忽略 |
| `src/pages/Sudoku.jsx` 数字面板 | 点按 1~9 / 键盘数字键 | 对选中格写入；已知格与「已确认」格不可改；写入后自动选中下一空格 | 无选中格时播报提示，不写入 |
| `src/game/SudokuEngine.js` 填入校验 | 数字面板输入 | 与终解比对：正确 → 锁定为已确认；错误 → 错误 +1、扣 30 分、红标抖动 300ms；错误满 3 次判负（fail） | 判负后得分 0，盘面锁定 |
| `src/pages/Sudoku.jsx` 笔记模式 | 开关切换后输入 | 候选数小字填入（每格 ≤9），不校验对错、不参与完成判定；正式填入清空本格笔记并剔除同行/列/宫相同候选 | 笔记不触发错误计数 |
| `src/game/SudokuEngine.js` 提示 | 每局 3 次 | 填入选中空格正解（未选中则取第一个空格），扣 50 分，计为已确认 | 次数用尽返回 null，按钮禁用并播报 |
| `src/game/SudokuEngine.js` 撤销 | 撤销栈 ≤50 步 | 回退填入/擦除/笔记/提示四类操作 | 撤销不恢复错误计数与已扣分（防刷分）；栈空按钮禁用 |
| `src/game/SudokuEngine.js` 完成判定 | 每次填入后检查 | 81 格全部已确认 → win，结算得分 | 含笔记格不算完成 |
| `src/pages/Sudoku.jsx` 计时 | 首次有效填入/提示开始 | 每 250ms 调 `tick()`；倒计时归零判负（timeout），得分 0 | 暂停期间计时冻结 |
| `src/game/SudokuEngine.js` 计分 | 仅胜利结算 | `max(100, 基准分 − floor(用时秒)×2 − 错误×30 − 提示×50)` | 判负/超时不得分 |
| `src/pages/Sudoku.jsx` 双路暂停 | `visibilitychange(hidden)` + `window blur` | 标记位去重只暂停一次；遮罩遮蔽全部数字；输入/提示/撤销失效 | 恢复以当时刻为新基准继续累计（约束卡②） |

| `src/pages/Home.jsx` 入口卡 | 新增第 20 张卡 | 「数独」→ `/sudoku`，描述与引擎数值一致（三档挖空数/限时） | 统计条由 `ENTRIES.length` 驱动，不改代码 |

## 5. 状态说明

| 状态 | 触发时机 | 界面表现 | 可用操作 |
| --- | --- | --- | --- |
| 加载 | 选择难度后 200ms 内 | 全屏遮罩「正在出题…」+ 旋转指示器，`role=status` 播报 | 无（等待） |
| 空 | 本机无任何最佳记录 | 开始页难度列表下方虚线框「暂无最佳记录，通关一局后自动保存」；HUD 显示 `—` | 选择难度开始 |
| 错误 | 生成失败（挖空尝试耗尽 / 意外异常） | 遮罩「出题失败」+ 说明 + 「重试」「返回首页」 | 重试按上次档位重新生成 |
| 暂停 | 手动暂停 / 切后台 / 失焦 | 遮罩完全遮蔽盘面数字，计时冻结 | 继续 / 返回首页 |

边界情况：

1. 唯一解复核失败：回退该对空格重挖，单盘 200 次尝试耗尽后重新生成终盘，至多 3 次。
2. localStorage 不可用 / JSON 损坏：读取回退空结构；写入失败置 `saveError`，游戏继续，结算页提示「本局成绩未保存」。
3. 寄语 API 超时 / 断网 / 响应结构非法：降级本地句子池（8 条），按日期确定性选句，当日写入缓存避免重复请求。
4. 暂停时窗口再次失焦：标记位已置位则跳过，保证只暂停一次。
5. 撤销栈空 / 提示次数用尽：对应按钮禁用并播报，不抛错。
6. 非法难度参数：回退 easy，不抛错。

## 6. 非功能需求

- **性能**：终盘生成 + 挖空 + 唯一解复核合计 ≤200ms（解计数器计到 2 即停）；`tick()` 周期 250ms；不引入任何第三方依赖。
- **兼容**：无后端；盘面为纯 DOM 网格；页面 `min-height: 100svh` + `overflow-x: hidden`；`prefers-reduced-motion` 关闭全部过渡与抖动动画。
- **移动端热区策略（关键决策）**：9 列棋盘在 320px 视口下每格约 34px，无法达到 40px。因此**格子使用 `div[role="gridcell"]` + roving tabindex，不使用 `<button>`**；点选格子仅做选中（低成本、可纠正），全部写入动作收敛到 ≥40px 的数字面板与功能键。≥360px 视口下格子自然 ≥40px。移动端审计的热区选择器为 `a, button, input, select, textarea, summary, [role="button"]`，gridcell 不在其列，不会被误判为小热区；此与扫雷「8 列铺满 320px」同属按列数适配窄屏的既定策略。
- **埋点**：`game-sudoku-stats-v1` 脏标记 + 1s 防抖落盘，`pagehide` 与页面隐藏时强制 flush；计数 0~99999 封顶。
- **约束卡①（已知不一致点联动修正）**：每日挑战轮换池 11→16 款，落点 `src/api/dailyChallenge.js`、`dailyChallenge.test.js`、`src/docs/daily-challenge.md`、基线第 5 节；抽题分布变化已在第 2 节显式声明。
- **约束卡②（切后台/失焦）**：双路去重暂停 + 计时冻结 + 盘面遮蔽，落点 `Sudoku.jsx` 监听与 `SudokuEngine.js` 的 `pause()/resume()`。
- **约束卡③（外部 API 与失败降级）**：Hitokoto 3s 超时 + 本地句子池降级 + 当日缓存（≤200 字符不写），落点 `Sudoku.jsx` 结算区与 `game-sudoku-quote-v1`。

## 7. 验收标准

1. **Given** 开始页选择任一难度，**When** 点击开始，**Then** 先出现加载遮罩，随后盘面出现且已知格数与档位一致（45/35/29）。
2. **Given** 同一随机源，**When** 生成两局，**Then** 题目可复现；不同对局题目不同；每题经解计数器复核唯一解。
3. **Given** 游戏中选中空格，**When** 点数字面板填入正确数字，**Then** 该格锁定为已确认并播报「填入正确」，焦点自动移到下一空格。
4. **Given** 游戏中，**When** 填入与终解不符的数字，**Then** 错误计数 +1、扣 30 分、该格红标；错误满 3 次进入判负结算且得分 0（异常）。
5. **Given** 游戏中，**When** 使用提示，**Then** 填入选中空格正解并扣 50 分；第 4 次点击提示按钮时按钮已禁用并播报「提示次数已用完」。
6. **Given** 已有填入与笔记，**When** 点击撤销，**Then** 回退上一次操作但错误计数与扣分不恢复；栈空时撤销按钮禁用。
7. **Given** 游戏中，**When** 切后台再切回、或窗口失焦再聚焦，**Then** 只触发一次暂停，盘面数字被遮蔽、计时冻结，继续后从暂停处累计（异常）。
8. **Given** 81 格全部已确认，**When** 最后一格填入完成，**Then** 进入胜利结算，得分 = `max(100, 基准 − floor(秒)×2 − 错误×30 − 提示×50)`；倒计时归零则判负得分 0（异常）。
9. **Given** 胜利结算，**When** 网络正常，**Then** 寄语区显示一言句子与来源；**When** 断网或 3s 超时，**Then** 显示本地句子池句子并标注「离线寄语」，同日再次胜利直接读缓存（异常）。
10. **Given** 本机已有某档最佳记录，**When** 以更低于记录的成绩通关，**Then** 记录不被覆盖；无记录时开始页显示空态文案。
11. **Given** 首页，**When** 查看作品入口与统计条，**Then** 出现第 20 张「数独」卡并可跳转 `/sudoku`，统计条显示 20；**When** 查看今日挑战，**Then** 轮换池含数独共 16 款且同日抽题结果确定。
12. **Given** 320/360/375/414/480/600/768/820/1024 九档视口，**When** 审计开始态与游戏中态，**Then** 无横向溢出、无 <12px 字号、数字面板与功能键热区 ≥40px；reduced-motion 下无动画；Tab 进入盘面后焦点停在选中格。
